# 剧本三：中国古代卡通完整游戏素材包

这是《布衣定鼎》的独立运行时美术包。它只使用本轮确认的中国古代卡通方向，不引用旧的写实资产、像素实验包或前期扩充图集。

## 美术定调

- 题材：架空中国古代，围绕淮河饥荒、漕运水战、江东经营、北伐与开国制度建设。
- 视觉：高斜俯视战术卡通；头身比紧凑；粗墨线；哑光、克制的土色、橄榄绿、靛蓝与旧金；两段式赛璐璐明暗。
- 历史语法：以宋、元、明常见的河防、军械、舟师、服装和基层行政器物为参考，但不复制单一真实王朝。
- 叙事原则：低奇幻、制度驱动；粮、地、税、军籍、河工、户册与证据均需要真实可视化。
- 禁止：日本武士与忍者语汇、鸟居与日式城郭、仙侠法术、现代武器、科幻机械、照片写实、油亮 3D、像素画。

## 目录

- `masters/`：本轮内置图像生成得到的原创母图。
- `intermediate/alpha/`：色键去背中间图。
- `runtime/`：游戏直接读取的独立 PNG 与动作条/状态条。
- `previews/`：单位、地图资源、图标特效和剧情静态总览。
- `manifest-final-ancient-china-v1.json`：404 项运行时清单与尺寸、帧、锚点、连接规则。
- `qa-final-ancient-china-v1.json`：覆盖、重复、透明色残留、动作帧和建筑三态检查。
- `tools/build_final_ancient_china_v1.py`：从母图确定性重建运行时资源。

## 运行时契约

- 普通单位单帧为 `32×48`；骑兵、工程编队等使用 `64×48`，大型舟船或攻城器械使用 `96×64`。
- 单位每项 4 帧横排：`idle / walk-a / attack-or-work / walk-b`，锚点为底部中心。
- 交互建筑每项 3 帧横排：`normal / damaged / captured`；损坏必须改变主体结构，占领通过旗帜和控制标志表达。
- 地形单元为 `32×32`；连接类使用 N/E/S/W 16-mask，其余使用 4 个独立变体。
- 图标使用透明底；剧情场景与角色卡保留完整背景。

运行时只应读取本目录的最终 manifest，不要混用 `runtime-v2/`、`expanded/` 或 `draft-v1/`。
