# 剧本二 · 卡通科幻完整游戏素材包

这是剧本二独立的新美术生产包。它以已定稿的斜俯视卡通科幻地图为唯一视觉基准，不复用旧的写实概念图或像素 `runtime-v2` 作为最终游戏资产。

## 交付规模

- 正式运行时资产：404 个透明或不透明 PNG
- 原创生成母图：70 张
- 战斗单位：40 个，每个 4 帧；大型载具/共生体保留 64 或 96 像素宽帧
- 任务单位：24 个，每个 4 帧
- 阵营基准 12、地形 32、交互建筑 24、战场物件 32
- 装备 48、技能 48、状态 24、FX 24、HUD 16
- 剧情静态资源 80

## 使用入口

- `manifest-final-scifi-v1.json`：游戏接入唯一清单
- `runtime/`：最终游戏 PNG；不要直接接 `masters/`
- `previews/`：四张总览图
- `qa-final-scifi-v1.json`：自动验收结果
- `tools/build_final_scifi_v1.py`：从母图确定性重建运行时文件

## 视觉与语义规则

- 统一为原创卡通战术游戏风格：大头紧凑比例、粗深色轮廓、克制哑光配色、两段式明暗。
- 赫沙使用陶瓷、水封和赤砂；索勒使用蓝冰、保温层和热灯；涅瑞亚使用潮汐膜材、浮台和潮锚；维尔达使用可维护共生组织；凯隆使用标准化轨道与权限硬件；厄客使用实体档案与受控回声投影。
- 单位按工具、材质、轮廓和动作共同表达职业，不允许用同一套科幻装甲换色代替。
- 青色表示水、星脉和护盾；橙色表示热能、动能和工业警示；紫色只用于厄客记忆、寂潮和权限异常，并保持低饱和。
- 米拉、罗安、奈姆、塔洛斯七号、赫洛和伊娅的阶段变化必须保留身份连续性。
