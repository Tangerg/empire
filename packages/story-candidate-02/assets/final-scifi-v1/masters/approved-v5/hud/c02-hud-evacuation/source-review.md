# c02-hud-evacuation

Full legacy board audited and motif visually matched to legacy runtime before generation. Exact request and input hashes are retained locally. Built-in image generation used, one asset per call. Raw and master bytes are identical, with alpha untouched.

Source and native32 export visually reviewed on white, black and olive. Native output uses repository export_overrides.fit_canvas: full canvas contained to 28x28 centered within 32x32; no crop, threshold, repaint or alpha replacement.

Review caveat: Small ramp grid and jamb strips simplify at native32. Cyan doorway and outward ramp remain readable. Central cyan is a bounded filled portal/panel as in legacy, not alpha.

Candidate ready for integration review, not a claim of individual user approval or in-game verification.
