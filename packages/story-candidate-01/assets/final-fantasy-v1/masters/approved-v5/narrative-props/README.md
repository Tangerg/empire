# First four narrative key-props

Four selected native1254x1254 genuine RGBA sources, generated independently with built-in image_gen. Four actual generation calls, no rejected attempts. All raw/generated/master bytes are identical within each topic. No source alpha cleanup, chroma-key, crop, resampling or repaint was performed.

Per-topic folders contain master.png, raw/attempt-01.png, prompt.txt, request.json, hash.sha256, sourceproof.json, reference-audit.json and QA/. Original617px cells and cited lore were inspected before generation. The reference establishes the existing object identity; the approved broad-form matte prop source establishes the rendering style.

Full references, native masters, exact128px black/white/olive/dark composites pass visual QA. All loose bridle parts and open metal gaps remain separate. All three plain biscuits remain countable. The guard remains cylindrical without fingers. The crown remains an incomplete curved band with diamond boss.

Hardtack and crown each have tiny native boundary-alpha1 values (35 and11 pixels respectively). They are retained unchanged under the audited tolerance; native white/dark and128px composites were visually checked for fringe and cutoff. Guard and bridle boundaries are alpha0. All128px derivatives have transparent boundaries.

QA derivatives use ImageOps.contain(source,(124,124),LANCZOS) followed by unmasked paste at(2,2) into128x128 RGBA; no bounding-box crop. The script may be rerun with the four topic slugs. Source byte copies stay unmodified.

No repository, Git, registration or production export files were edited. These deliverables establish source artwork readiness only; formal binding and live-game acceptance are separate parent work.
