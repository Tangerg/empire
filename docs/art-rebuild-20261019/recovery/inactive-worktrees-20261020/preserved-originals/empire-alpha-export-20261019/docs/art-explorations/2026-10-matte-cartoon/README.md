# 哑光卡通美术探索样张

本目录归档 2026 年 10 月对话中通过 AI 图像生成工具制作的 8 张探索样张，供美术方向与后续制作参考。角色、道具依据项目原素材优化；建筑和场景依据三套主题参考图重新设计。它们不是《王国保卫战》的原始素材，也未对生成模型版本作保证。

用户认可的最新场景方向是：克制的色彩、哑光质感、清晰轮廓，以及更丰富的树冠、植被、地形和建筑细节层次；避免过艳、油亮和大面积强高光。此方向的认可不等于所有样张均已通过运行时验收。早期角色、道具与建筑样张保留各自阶段的效果，并未自动重绘为最新场景风格。

## 与正式素材的边界

- 本目录只归档探索图，不替换现有素材、Manifest、地图数据或渲染逻辑，也不改变各剧本的正式美术规范。现行入口仍是 [三套剧本素材文档](../../story-candidates/ASSETS.md)
- 大地图是完整合成的概念场景，不是可直接使用的 tilemap：未提供格子坐标、地形规则、碰撞、遮挡层、可走区域或单位部署数据
- 建筑上的人物、旗帜和特效已与建筑合成在同一张图内，没有独立图层、骨骼或动画帧。要制作动作，需要拆分并补绘被遮挡部分，或另外制作角色与特效帧序列
- 接入 SRPG 前需确定镜头与投影、格子尺寸、缩放、落脚锚点、占地与选取区域、前后遮挡关系；分别制作地面、装饰、建筑、单位与动画，再在实际界面验证可读性
- 透明样张仍需检查目标缩放下的边缘与主体 alpha，不能仅凭“存在透明通道”视为生产完成；古风弩塔人物的装备也需进一步统一主题
