## Important identity/crop findings

- **Dragon Covenant has a literal balance-scale shield emblem**, a gray overlapping-scale swatch with wine-red edging and a separate buckled loop. It does not depict a dragon-head emblem. Do not replace its source emblem or introduce a dragon saddle/bridle.
- Lorne and Vilsa both have upward ivory chevrons, but different shield palettes, trims, textiles and weapons. Preserve these differences.
- Holy Light uses a candle/holder shield and stamped seal; Named Dead uses a lantern shield, two name tags and a separate lamp. Keep those symbols distinct. The source marks are not a basis for invented readable writing.
- Gray Banner, Silverwood, Wasteland and Militia-Mercenary are identified primarily by repaired materials and object silhouettes, with no large independent faction crest to invent.
- Oath Controlled retains the Lorne-like shield/cloth/sword group and adds crossing and horizontal inscribed binding bands. Late Alliance visibly preserves multiple cloth colors, buckles and linked fasteners rather than one imperial symbol.
- The legacy 5px inset removes alpha-core pixels (threshold 28) from **Silverwood 162px, Militia-Mercenary 46px and Late-Alliance 18px**. Gray Banner and Wasteland also reach the inset boundary, although no extra core pixels are lost there. Silverwood’s shield already reaches the full-board left edge. These observations mean the remake must restore clean complete outlines, not reproduce old cuts.
- The old master is an opaque magenta RGB board. Existing alpha intermediates use historical chroma cleanup. Neither is a compliant new true-alpha master. Keep them as identity references only.

## Actual consumers

The ordinary Vite asset glob in `candidate-01-assets.ts:179–184` includes all faction PNGs; the generic topic catalog resolves them at lines 196–231. No authored direct gameplay/UI topic or runtime-path references were found across 434 code files in apps/packages/tools and 5 source JSON documents. The earlier `grayflag-topic-consumers.json` audit agrees. Generic APIs can accept external/dynamic topic input, so the finding is specifically “no authored consumer found,” not a claim that consumption is impossible.

The explicit family-specific consumer is the offline `previews/map-assets-1x.png`, generated by the legacy builder at line 497. No browser gameplay use was asserted or observed. This remake should not add a new gameplay binding merely to claim usage.

## Minimal exporter contract

Extend the existing static contract table in `tools/art/export_overrides.py:255` with `'faction-kit': 128` and update its unsupported-category diagnostic. Keep the existing `{source, sha256}` specification, pack-masters confinement, full-canvas containment, real-alpha/edge checks, `[64,64]` center-anchor check and canonical `runtime/faction-kit/` destination. Keep the current rejection of non-battle-prop HD records.

No new exporter, composite kind, crop field, frame sequence, HD manifest or pivot calculation is needed. One independent immutable true-alpha master per topic is sufficient. Recommended source location: `masters/approved-v5/factions/<faction-slug>/master.png`. New square masters should arrange the complete source object group with useful transparent margins; do not inherit the old board cell’s large empty top/bottom regions. Full-canvas fitting must remain explicit, without alpha-bbox inference.

Before promotion, test valid deterministic 128px export/check mode, wrong dimension/anchor rejection, bad hash/path/RGB/clipped-alpha rejection, framed/variant/HD rejection, unchanged topic/path/count and canonical runtime resolution. Review all full masters and 128px light/dark output against the source object sets and emblem topology. Existing promotion/ledger operations should then record only what is actually verified.

Do not run the legacy complete builder: its `packages/story-candidate-01/assets/manifest-complete.json` input is absent, and its main routine would overwrite unrelated assets. This audit imported only pure legacy crop/fit helpers, with Python bytecode writing disabled, and reconstructed in memory from the existing alpha image.
