# Forty canonical combat topics

All forty canonical Gray Flag combat topics now have reviewed four-pose source bundles and formal 1x/2x catalog bindings. This contact sheet uses the actual HD idle sheets at their declared logical size and anchor, not uniformly fitted thumbnails. It includes catalog-only units and is not a deployed formation or live-game capture. Named hero and red-team appearance variants add no canonical topics.

Visual review: broad outlined forms and material palette are broadly consistent. Role-scale exceptions remain visible: compact frontline swordsman framing, larger constructs/mounts, and floating ghost/spirit anchors. This sheet does not establish every unit's full-scene clearance or animation playback acceptance. Previously documented troll neighbor overlap and Ivra portrait-age continuity remain open. All original source and pose-specific evidence is retained separately.
