# Catalog binding and unresolved placement

The complete four-pose source bundle is bound only in the canonical C02 catalog. The source support measurements reduce interphase drift to 0.140 px X and 0.488 px Y without relaxing the existing ±2 registration limit. The declared anchor (32, 63) and 2×2 footprint are unchanged.

A common 2.742–3.230 px vertical visual-baseline gap remains unresolved for actual scene presentation. There is no current C02 playable consumer, so this catalog binding does not establish that the mount will not appear to float. A same-scale shared-renderer diagnostic now shows the measured support centroids inside the existing contact-shadow ellipse, with no clean empty horizontal band above it. Outer hooves remain outside the generic shadow, and there is still no genuine C02 scene acceptance. The exact scope and a preserved-original source-correction proposal are in baseline-gap-review.md; neither a weaker offset guard, cropping, nor a hidden anchor change was used.

The primary acceptance is the exact native 64 output. A secondary 32 downsample has perimeter alpha 3 ringing and is explicitly not an accepted runtime density. Neither full-scene readiness nor live gameplay is claimed.
