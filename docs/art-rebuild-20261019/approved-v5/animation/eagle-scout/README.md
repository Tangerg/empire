# Eagle scout

Four source-consistent grounded fantasy-mount poses are formally registered in canonical and HD catalogs. Shared 52/944 scale, measured support translations (maximum 2.644 logical pixels), full authored canvas retained with at most two native pixels of transparent padding. Original rider, four taloned legs, folded wings and bow preserved; opposite walking supports and drawn-bow attack reviewed in actual 1x/2x exports on three backgrounds.

The design role mentions flying reconnaissance, while the high-resolution original depicts grounded four-legged anatomy. This replacement preserves the original drawing; it does not introduce flight rules. No current deployed consumer exists. Live playback remains unverified.

Rejected walk and attack candidates are preserved. The immutable first attack source remains at its earlier repository path; the corrected selected source is explicitly referenced under attack/selected-correction-03 in registration.json and repository-selected-sources.json. Source alpha is never normalized.
