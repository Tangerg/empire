Generated 2026-10-20 using exactly four independent built-in image_gen.imagegen calls, one per canonical source. No CLI fallback. Work authored only in this review directory and canonical-terrain/uker-* source directories. No shared code, catalog, runtime, manifest or Git edits. These are proposed sources, not live assets or a claim of final style acceptance.

## Original subject and source audit

No Uker approved/raw source directory existed before this work. Existing original runtime strips are historical material, not newly approved sources. The complete original masters/terrain/terrain-board-03.png was inspected, rather than guessing subjects from names. The topic catalog at docs/story-candidates/candidate-02/art-assets/07-topic-catalog.md orders indices 20–23 as grave fragments, physical ruin, memory overlay, reality rebuild. The original builder build_final_scifi_v1.py consumes boards row-major, four columns and two rows each. Therefore these are board 03 bottom-row columns 1, 2, 3, 4. Canonical manifest order is grave fragments, memory overlay, physical ruin, reality rebuild; original-manifest-entries.json preserves exact records and geometry. Original strips were also inspected and copies plus hashes are in original-reference and source-inventory.json. The original manifest-complete.json input is absent and is not claimed inspected.

Original board subject: blue crystals on red-brown ground; gray-green physical masonry ruins; violet ghost architecture over paving; rust/purple reality transition with bright violet dividing seam. These identities, not the original rendering density, guide the new sources. Only the approved Farlight cargo-hold master was used as style reference. No Soler source was used.

## Preservation and checks

All outputs are opaque RGB 1254×1254 PNGs. raw.png and master.png are exact returned file copies without repainting, resizing, recoding, hidden cropping or color adjustment. Each source directory contains prompt.txt, request.json, generation-result.json and provenance.json. Provenance hashes the master and both reference images; checks.json additionally hashes prompt/request. proposed-registration.json records source hash, actual size and exact sampling windows. Grave fragments uses four 627×627 quadrants TL/TR/BL/BR. All three NESW materials use the full square.

build_review.py imports existing read_material/render_material helpers without changing shared registration or exporters. Isolated native32 previews use established Lanczos sampling, historical masks and one-pixel opposite-edge matching. All alpha strips equal original runtime alpha bytes exactly. Distinct cells: 4/16/16/16. Exact edge checks pass 16 east-west + 16 south-north variant pairs, and 64 + 64 allowed pairs for each NESW strip. These checks prove outer-edge equality, not seamless interior motif continuation. checks.json and native-review.json contain detailed evidence.

## Visual review and limitations

Inspected complete original atlas, original native strips, all four complete generated masters, all-zoom2.png and all four native32 connected grids. All grids show black, white and olive backgrounds and derive masks from actual cardinal occupancy. Enlarged previews are nearest-neighbor diagnostics, not HD runtime deliverables.

- Grave fragments: large cyan/cobalt crystals read immediately against rust ground. Four complete, distinct clusters survive native reduction. Crystal shapes retain more than exactly two faces and some soft shading, but are broad rather than small-faceted. Ground has more slab divisions than requested. Repeated crystal clusters remain obvious in larger filled areas; there is some raised-object perspective rather than a perfectly flattened surface.
- Memory overlay: purple ring and ghost-foundation shapes distinguish it clearly from physical masonry. Full source retains diagonal painted patches and small cracks despite the anti-mottling instruction; it is not literally flat two-tone. Native masks primarily reveal the central ring and short purple paving arms, cropping most corner ghost architecture. Grid reads as repeated purple circular junctions, not a continuous ghost city. This abstraction must be accepted deliberately, not represented as exact preservation of original architecture.
- Physical ruin: subdued olive-gray masonry with thick dark seams and turquoise remnants reads as physical rather than projected terrain. Source surfaces are comparatively quiet, with sparse chips, bevels and shadows. It exceeds the requested five principal shapes. Narrow masks suppress most turquoise and crop the large block foundations; native appearance is masonry fragments with visible repeated junctions. Low contrast against olive background remains.
- Reality rebuild: orange/purple split, violet fissure and central node remain strongly distinguishable at native32. Full source has broad mottled paint patches and secondary stones beyond requested simplification. NESW masks retain the reconstruction node and vertical energy seam; E/W arms show the two different terrain colors. Repetition is conspicuous, and opposite-edge matching creates a narrow color transition where orange meets purple at horizontal tile joins. Edge equality is exact but does not make these interior materials visually seamless.

All NESW sources retain inherited narrow cross/capsule alpha geometry. This task does not redesign that topology. There is no animation, gameplay effect, new consumer, scene integration or HD output.

Recommendation: mechanically valid, native-inspected candidates for parent review. Do not mark all four unconditionally style-approved: memory overlay and reality rebuild especially retain broad surface patching inconsistent with the strictest flat-fill goal. One generation per source was honored, with no concealed cleanup or extra regeneration. Parent owns acceptance, any separate revision decision, formal registration, export and whole-pack/scene validation.
