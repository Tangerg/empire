# Empire 全量美术重制基线

基线：2276a89f75b5a6734e6347f62941d4a0e5b37d03（远端 main 已核对）。设计参考：样例提交 ac2a95ef923ea040620b8691d5733365a36ca0a4 的三个 matte-detail-v3 场景。采用哑光、克制色彩、丰富但分层的手绘卡通细节；不复制商业 IP。

## 固定范围和计数

- 三题材各404个稳定 topic，共1212个题材，包含剧情、单位、阵营、地形、建筑、物件、装备、技能、状态、特效、HUD。
- 灰旗环境建造包另有36套图集，1188个组件。连接掩码、尺度、帧和状态不能算成新的独立题材。
- 原始1896个图片文件中1857个位于生产包，39个是文档截图/历史参考样例，保留不重画。生产文件含205母图、169中间图、21预览、1285运行图、177高清运行图。
- 177高清图中176对应正式题材，另1张连续地表来自已有地形母图。另有旧森林图集依赖，单独跟踪，不能遗漏也不能重复算题材。
- 29组字节完全相同的文件已列出；其余不同字节并不代表独立设计。
- 盘点创建时尚未重制题材；当前状态以 progress.json 为准。raw-generated 只表示新母图保全，不表示可直接用于游戏。

## 交付顺序

1. 灰旗4个静态战场物件验证透明导入/缩放流程：木箱堆、风蚀岩、灰旗组、战地药箱。
2. 灰旗其余物件、装备/技能/状态/HUD，再做叙事角色和道具；每个小组完成后保存并推送。
3. 灰旗角色动作、建筑三态、地形变体/连接图、特效，保持相同 topic 和帧/锚点合同。
4. 灰旗36套环境图集和场景实机可读性验证。
5. 科幻、古代中国各404题材，以同样分类和验收顺序完成。
6. 重建全部派生输出/预览，检查消费者、真实渲染、缺项，最终才能宣告全量完成。

## 透明与质量验收

人物、道具、建筑、图标及需要叠加的图层必须有真实 alpha；不能用棋盘格或背景色冒充。全铺地表、完整剧情场景可以不透明。必须看实际小尺寸和深浅背景合成，检查边缘污染、裁切、轮廓、材质、比例、锚点、帧间一致性与遮挡。64个现有透明类别输出实际全不透明，说明历史 runtimeReady 并非新版验收证据。

## 已知生产风险

三个旧构建器依赖缺失的 manifest-complete.json 和外部去背脚本；部分角色卡强制 RGB/fit_opaque。不能只替换 runtime 后宣称可复建；新母图必须通过可重复的透明导入与导出链。母板到题材的历史映射依赖已缺失清单的顺序，禁止擅自把字母排序当原顺序。优先为稳定 topic 建立显式源映射，未核实映射保持标记。

## 数据文件

- canonical-topic-manifest.json / csv：全部1212题材、精确文件、帧/锚点合同、透明要求、高清派生路径。
- file-inventory.json：所有基线图片的尺寸、模式、alpha分布、字节哈希、角色分类；没有修改图片像素。
- environment-atlas-manifest.json：36图集的尺寸、组件、类别与运行路径。
- byte-identical-groups.json：完全重复文件，仅辅助避免重复生产。
- progress.json：重制状态唯一记录；只根据对应证据推进，不能以复制次数增加进度。

已核实灰旗消费链：candidate-01-assets.ts 读取正式与高清 manifest；candidate-01-runtime.ts / candidate-01-story.ts 消费资产；candidate-01-environment.ts 和 candidate-01-map-scene.ts 消费环境图集。其它题材当前是内容包；本清单不声称已在游戏内逐项使用或完成视觉验收。

## 新增来源与语义审查规则

细小图标、阵营徽记和疑似错切素材先核对高分辨率母板，不能把排序后的 manifest 顺序当成母板槽位。古代中国部分运行图存在混合碎片；完整母板与语义标签能确认物件时允许重建，并明确标为 reconstructed_identity，不能声称恢复了准确的历史裁切。语义失败的新图保留母图和修订历史，运行输出暂时恢复基线；更正后重新验证再启用。

第一名剑士试点允许最多2个逻辑像素的可见脚底偏移，但必须四姿态共同尺度、共同位置、透明边缘合格且视觉稳定；声明锚点不变。这是该试点的窄范围审查决定，不是其他单位或场景的通用放宽。
