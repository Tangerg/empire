# Exaggerated bridgehead concept study

The user requested a stronger exaggerated style resembling Legends of Kingdom Rush. This bounded study uses the previous staged bridgehead image as composition reference and an official game screenshot as drawing-language reference. The original soldier, pine and bridge masters were inspected. Built-in image generation produced v1, then a targeted v2 revision strengthened expressive veteran faces, broad hands and blades, angular grouped tree crowns, and bold cel-shaded forms.

Selected deliverable: `before-after-concept-v2.png`. Standalone labeled concept: `concept-v2-labeled.png`. Raw v1/v2, original comparison image, exact prompts and file hashes are preserved.

Six soldiers, blue/red teams of three, three horizontal bridges and the vertical river remain clearly recognizable. Camera and formation approximately correspond. The model re-authored character size/standing centers, tree silhouettes/partial edge-tree visibility, ground boundaries and material drawing. It is therefore not a strictly registered same-layout rendering.

This is an opaque whole-scene CONCEPT, not runnable art, a gameplay capture, a transparent sprite sheet or a completed production remake batch. It adds zero to transparent asset completion counts. Production assets, renderer and level data were not changed. Future separable asset work still requires genuine alpha and in-engine validation after the style direction is accepted.

Reference: official Legends of Kingdom Rush Steam store imagery, https://store.steampowered.com/app/1904860/Legends_of_Kingdom_Rush/ . Official screenshot pixels are not packaged into the project assets.
