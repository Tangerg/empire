# Bounded style prototype for direction review

The latest selected-layer study uses seven source identities: swordsman, pine, Lorne Keep, stone bridge, river material, muted road material v2, and riverbank v2. It retains actual c01-02 tactical topology and selected existing placement points. Five party positions deliberately share one swordsman identity; five forest positions deliberately share one pine. Other actors and buildings are omitted to expose the new art language. The mixed-legacy diagnostic remains available separately.

Visible human height34, pine90, keep width128, bridge width96. Every sprite retains its full generated canvas and measured source attachment point. The bank appears only once below the last bridge. Native and2× previews are generated from actual high-density sources and production renderer pieces, with explicit clipping. This is an art study, not a gameplay screenshot.

The isolated connector adapter removes old alpha bars and doubled shoulders. The water-area layer uses unchanged water/bridge cells and diagonal occupancy checks, leaving no holes or pixels outside water occupancy. Broad water UV sampling is continuous in world coordinates. None of these calibration outputs replace production assets.

Still unresolved: straight macro terrain shapes, legacy ground clutter/foundations, homogeneous substituted actors/trees, and runtime lighting/camera/animation. Normal keep is a deliberate shape-study substitution for the actual owned/captured state. Full concept acceptance and bulk production remain paused pending user direction.
