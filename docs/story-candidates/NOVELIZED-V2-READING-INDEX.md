## 共用阅读规则

- 按各目录 README 顺序连续阅读，不先读分支附录。
- 章节开头直接处理上一章末尾留下的声音、物件、故障、欠账或命令，不另写前情提要。
- 正文没有关卡号、触发器、角色名加冒号或并列选项。
- 静态素材沿用各候选目录 `assets/` 中的现有文件与稳定编号；小说目录只提供镜头和连续状态，不改动素材文件。

## 制作同步顺序

先固定每部贯穿物的连续状态，再补大场景：

1. 《断冠之誓》：左手护腕、烟熏灰旗、龙盟断扣、期限扣。
2. 《群星熄灭之前》：凹口金属杯、折叠桌、伊娅的门、罗安风险清单。
3. 《布衣定鼎》：官粮封条、鞋底账、三态白灯、沉船名册与新旧田册。

这些物件承担章与章之间的视觉接缝。角色换装、城市升级或时间跳跃时，物件的磨损与修补必须保留。
