# 按《断冠之誓》的运行时规格交付

本页定义《断冠之誓》可以直接进入战棋引擎的文件规格。概念图、母图、原型 atlas 和大尺寸剧情样包不能代替运行时交付。

## 使用统一文件基线

游戏以 `32×32` 为基础棋盘格。PNG 是运行时格式，SVG 只用于审阅与可复现导出。所有坐标和缩放使用整数，渲染采用 nearest-neighbor。

| 类型 | 必须交付的规格 |
| --- | --- |
| 标准单位 | 四帧横排，单帧 `32×48`，锚点 `(16,47)` |
| 大型单位 | 单帧 `64×48`、`64×64` 或 `96×64`，声明足迹、锚点与层级 |
| 非连接地形 | 单格 `32×32`，至少 4 个稳定变体 |
| 连接地形 | 单格 `32×32`，提供北、东、南、西 16 个邻接掩码 |
| 材质过渡 | 单格 `32×32`，使用八邻域 Blob47，声明 N/NE/E/SE/S/SW/W/NW 位序 |
| 高差边缘 | `32×48` 或多格模块，声明高度差、坡道单元、阻挡和底部锚点 |
| 建筑 | 声明足迹与热区，至少交付正常、受损、占领三态 |
| 装备与技能 | 源单元 `32×32`，实机显示 24 至 32 像素 |
| 状态与界面标记 | 源单元 `24×24` 或 `32×32`，保持 1 至 2 像素最小线宽 |
| 特效 | 单元 `32×32` 或 `64×64`，使用 4、6 或 8 帧横排 |
| 剧情场景 | `256×144` 不透明 PNG，底部 32 像素避开关键证据 |

## 保持单位锚点稳定

单位源图默认朝右，朝左由游戏水平镜像。每帧脚底必须落在同一基线，武器、头部和坐骑不能被裁切。透明单位不带地面、外框或烘焙阴影。

## 制作可拼接地形

道路、河流、壕沟、墙体和熔沟使用 16 个邻接掩码。四边必须逐像素无缝。植被、火场、洪水与誓文控制层独立于基础地形，避免状态切换时重做整张地图。

地表材质交界使用八邻域 Blob47，不把 16-mask 道路规则硬套到海岸和草土边缘。基础地表变体必须共享锁定边缘，以便随机混铺。

## 绑定高低差

高差表现必须读取 `GameMap.elevation` 整数层。相邻格高度差为 1 时绘制一层岩壁，高度差为 2 时绘制或叠加两层；坡道只表现已由地图规则声明为可通行的边。美术不能自行创造隐藏高度，也不能覆盖 `maxClimb`、`maxDrop`、制高点、遮挡与视线计算。

## 定义建筑状态

旗点、粮仓、城门、工坊和烽塔至少包含 `normal`、`damaged` 与 `captured`。可关闭设施增加 `disabled`，可摧毁目标增加 `destroyed`。占领色放在独立旗帜或遮罩层。

## 声明清单字段

每项运行时素材必须声明稳定 `contentId`、精确 `topicId`、类别、PNG 路径、画布尺寸、帧数与锚点。大型单位和建筑还要声明 `footprint` 与 `zOrder`。特效还要声明 `fps`、`blendMode` 和 `loop`。

## 保持本剧本风格

所有运行时素材以 [`reference/art-direction-map.png`](./reference/art-direction-map.png) 为唯一视觉基准。灰旗使用银灰与暖琥珀，敌对誓军使用黑铁与受控红。森林、道路、河流和单位必须在 1× 画面中保持分层。
