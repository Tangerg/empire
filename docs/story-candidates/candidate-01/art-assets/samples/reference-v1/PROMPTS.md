# 生成记录

本轮使用 Codex 内置 ImageGen，所有生成都以 `../../reference/art-direction-map.png` 为唯一风格参考。统一要求为：俯视战术游戏资源、粗深色外轮廓、哑光手绘表面、克制饱和度、灰褐炭黑主色、透明资源先输出为纯 `#ff00ff` 色键底。

## 灰旗枪兵四帧

生成一个标准灰旗枪兵的四帧横排：待机 A、迈步 A、待机 B、迈步 B。同一名矮壮士兵，右向三分之四俯视角，钢制 kettle helmet、银灰软甲、炭黑靴、低饱和蓝灰罩衣，低位持一柄紧凑长枪。必须适合缩到 32×48；不得有背旗、旗杆、披风、文字、阴影或额外角色。

## 边境村庄三态

同一座紧凑木石村庄建筑横排三态：正常、物理受损、占领。三态维持同样地基、角度和比例；受损态包含破屋顶、裂石和破门；占领态保持完整建筑并增加小型空白蓝灰旗。暖琥珀窗光仅作小面积点缀。

## 灰旗箭塔三态

同一座木制箭塔横排三态：正常、物理受损、占领。三态维持相同石基、平台、梯子和角度；受损态包含塌台、断撑、裂基和破顶；占领态增加小型空白蓝灰旗。不得出现守军或飞行箭矢。

## 八种地形

4×2 网格：暖赭土路、冷灰蓝浅河、苔草地、暗松林地表、灰石桥面、岩石丘陵、覆雪山地、低矮灰石墙地表。纯俯视正交、无单位建筑文字、单格轴对齐、形状要能在 32×32 下识别。

## 八个装备与技能图标

4×2 网格。上排：长枪、圆钢盾、弩、工程锤；下排：长枪突刺、盾牌防御、治疗灯、琥珀誓火斩。每格只放一个粗轮廓中心符号，无文字、无数字、无装饰 UI 框、无手机游戏式高光倒角。
