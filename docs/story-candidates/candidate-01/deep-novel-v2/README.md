# 《断冠之誓》小说化深度版

本目录以小说式连续叙事重写《断冠之誓》。正文采用第三人称近距离视角，以莱娅为主视角，并在她缺席时短暂进入罗德里克、凯恩、布兰、米蕾尔等人的有限视角。

战役关卡仍保留原有 36 关因果，但不在正文中使用分镜编号、触发器说明或“角色名加台词”的脚本格式。战斗目标、系统变化和政治选择全部转化为人物当下的行动与后果。

七章小说正文合计约 9.42 万字；设定总控、分支与素材接口不计入正文规模。正文内不设任务单元式小标题，场景以伤口、粮食、账册、道路和未完成的争执自然过渡。

## 正史路线

小说正文采用“灰誓”方向的连贯主线，但不会把它写成无代价的完美路线。莱娅会犯错、滥用威望、第一次使用王冠并失去同伴；最终的灰誓来自多次失败后的制度重建。

其他选择不会塞进正文中并列展示，而在分支附录中说明怎样改变人物关系、战役资源与结局。
