# 《断冠之誓》深度定制版

本目录在原总纲与 7 章关卡稿的基础上补充场景、人物声线、连续性和生产接口。原稿继续作为事实底稿，本目录不覆盖原文件。

1. [创作圣经](./00-creative-bible.md)：本轮定制的叙事判断、角色弧与写作约束
2. 七章处理稿：[边境之火](./01-border-fire.md) · [灰旗流亡](./02-grey-banner-exile.md) · [古老诸族](./03-elder-peoples.md) · [灰旗女王](./04-grey-banner-queen.md) · [两种和平](./05-two-peaces.md) · [七塔战争](./06-war-of-seven-towers.md) · [无王之座](./07-throne-without-king.md)
3. [人物声线](./08-character-voice.md)：人物声线、关系节奏与对白样稿
4. [静态素材清单](./09-static-assets.md)：静态素材命名、优先级、镜头用途与现有资源映射
5. [连续性验收](./10-continuity-check.md)：伏笔、变量、时间与结局验收

## 素材目录

正式素材统一放在上一级 [`../assets`](../assets/) 中。本目录内的 `assets/` 只保留索引，不复制图片。

## 定制目标

- 保留“誓言成为魔法”和“能救人的绝对权力”两项原创支点
- 把人物从理念代表改写为有生活习惯、羞耻、私心和错误记忆的人
- 让九年跨度通过具体地点与普通人回访落地
- 让 36 场战斗各自推动关系、信息或政治后果，避免只换地图复述主题
- 给立绘、建筑、道具和关键场景提供稳定素材编号
