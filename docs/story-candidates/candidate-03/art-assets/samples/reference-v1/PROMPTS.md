# 生成记录

本轮使用 Codex 内置 ImageGen，以 `../../reference/art-direction-map.png` 为唯一风格参考。所有透明资源先在纯 `#ff00ff` 色键底生成，再通过本地确定性流程去底、切片和缩放。

## 统一历史约束

- 中国古代历史战争、农田水利、县仓与军需体系。
- 粗深色外轮廓、哑光手绘块面、自然靛蓝、旧铁、麻褐、浅土金、灰砖和青灰水体。
- 禁止仙侠、法术、符箓、发光纹样、飘带和奇幻兵器。
- 禁止日式武具与建筑、欧式骑士与城堡、现代设施和泛亚洲混搭。
- 不生成文字、徽记、UI、水印、地面阴影或透明素材以外的环境。

## 刀盾卒四帧

同一名矮壮普通兵卒的四帧横排：待机 A、迈步 A、待机 B、迈步 B。右向三分之四俯视角，铁盔、实用札甲、靛蓝麻衣、草缚靴，持带素环首的中国式单刀和小型圆藤盾。避免华丽将军甲和英雄化装饰，确保缩到 32×48 后仍能识别刀、盾和甲型。

## 河堤闸桥三态

同一座古代河堤闸桥横排三态：正常、物理受损、占领。灰砖桥台、木闸板、木绞盘、栓接桥面与小型灰瓦信号棚；受损态必须出现断闸、破板、裂砖和倾斜绞盘；占领态保持完整结构并增加短杆素靛蓝旗。

## 开仓粮站三态

同一座中国古代县仓式粮站横排三态：正常关闭、物理受损、占领开放。灰砖台基、木构灰瓦、土墙、双开木门、侧棚、麻袋、竹粮筐与手推粮车；占领态开门并显示有序粮袋，强调赈粮玩法。
