# 安排《布衣定鼎》的后续素材生产

下一阶段不再增加战斗单位。生产重点转向第一张真实河堤关卡，并验证田地、河渠、舟船、粮道、城防和普通民众在同屏时保持可读。

## P0 完成淮右河堤与开仓关卡

P0 把第一章升级为可复用的生产模板：

1. 接入灾田、泥地、河渠、田埂、泥路和浮桥地形
2. 接入堤坝、闸桥、粮仓、旗点、粮站和城门控制位
3. 接入刀盾卒、长枪阵、乡弓手、河工、饥民、农户和粮车夫
4. 接入开仓、护粮、修堤、火铳命中、暴雨和决口特效
5. 输出无程序占位图的真实关卡截图
