# 《布衣定鼎》小说化深度版

本目录将十八年、三十五战的开国故事改写为七章连续历史小说。正文采用第三人称近距离视角，以沈砺为主视点；当地方、军队或官署必须独立作出决定时，短暂进入陆青禾、韩岳、裴昭、江照夜、赵小满等人的有限视点。

正文采用“约法定鼎”正史。铁鼎与裂土结局后置附录，不在终章并排展开。

七章小说正文合计约 9.43 万字；设定总控、分支与素材接口不计入正文规模。

## 文体约定

- 不写关卡号、目标表、触发器或角色名加冒号。
- 不用现代政治口号替代田册、盟书、军籍、会审与限期。
- 战争先写鞋、粮、船、河道和伤员，再写旗号与胜负。
- 称帝不是收束，而是主角最危险的一段人物弧的开始。
