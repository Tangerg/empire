# 《布衣定鼎》高细节像素素材包

本包坚持低奇幻历史质感：视觉奇观来自河决、漕粮、城防、军旗和数以万计的普通人，而不是法术。16-bit 人物与建筑使用土色、湿靛和有限朱砂，HD-2D 场景把灯火、雨、水面和纵深作为现代增强层。

## 视觉 DNA

- 核心形状：粮袋、河堤折线、白纸灯、名册竖线、层层宫门。
- 核心材质：粗麻、深色木、湿土、瓦片、旧札甲、稻谷；所有材质带磨损，避免影视影楼般洁净。
- 色彩关系：土褐对应民生，湿靛对应治理，朱砂只用于官印/军令/高风险权力，白色只用于灾民互助灯。
- 服装原则：架空东方但时代内部一致；不用清代辫发、日本武具、仙侠飘带或皇族龙纹快捷符号。
- 武将原则：靠阵形、旗鼓、预备队和装备区分能力，不把任何人做成一骑当千的发光超人。

完整色值见 [style/tokens.json](./style/tokens.json)，可视色板见 [style/palette.svg](./style/palette.svg)。低细节首稿已整体移入 `draft-v1/`，仅保留为剧本覆盖和构图草案，不作为正式素材。

当前正式覆盖、历史缺口和分批补产顺序见 [PRODUCTION-GAP.md](./PRODUCTION-GAP.md)。下述扩展只补齐题材槽位原型，不代表 404 项运行时美术已经完成。可预览的运行时候选、精确覆盖与验收门槛分别见 [Runtime V2 素材画廊](../../RUNTIME-V2-ASSET-GALLERY.html)、[Runtime V2 覆盖状态](../../RUNTIME-V2-STATUS.md) 和 [游戏运行时素材契约](../../GAME-RUNTIME-ASSET-CONTRACT.md)。

两个轻返工没有覆盖旧文件：`c03-prop-grain-seal` 和 `c03-prop-temp-roll` 位于 `expanded/narrative/c03-prop-light-rework-atlas.*`。6 套既有实名英雄单位继续作为剧情运行时补充，不挤占 40 个通用战斗母型。

重新构建并验证本套资源：

```bash
cd docs/story-candidates/candidate-03/assets
```

生成器使用整数像素、有限色与同源 PNG/SVG 输出，不读取或覆盖 `draft-v1/`、`masters/` 和既有 `*-hd` 文件。

### 现行运行时规格

- 人物立绘：`96×112`；透明背景；建议以 2 倍、3 倍等整数倍显示。
- 单位图集：`128×48`；四帧横排，每帧 `32×48`；透明背景。
- 建筑立绘：`128×128`；透明背景；足迹和碰撞区域由引擎单独定义，不从透明边界推断。
- 剧情场景：`256×144`；16:9 全画幅；允许灯火、雨线、水光等 HD-2D 增强层。
- 道具图集：`192×48`；四件横排，每件 `48×48`；透明背景。
- PNG 是默认运行时版本；SVG 用于无损审阅、重着色与管线再导出。两种格式必须同名、同尺寸、同构图。

## 接入约定

- 单位图集每帧 `32×48`，四帧依次为站立 A、踏步 A、站立 B、踏步 B。
- 场景的 `hd2d-fx` 只放雾、灯火、水面亮线和雨；隐藏该组后，人物、粮袋、河堤和建筑必须仍然可辨。
- 朱砂色不得作为大面积阵营色；它是“官印/命令/高压权力”的叙事语义。
- 白纸灯不写字、不加宗教符号，保持从互助工具演变为政治标记的可塑性。
- 历史阶段换装优先改布料、磨损、腰带和随从距离，不用增加奇幻肩甲解决成长感。
