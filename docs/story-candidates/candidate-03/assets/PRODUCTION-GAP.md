# 《布衣定鼎》素材库生产缺口审计

> **历史基线：** 404/404 与两项轻返工只表示题材槽位原型已经登记，不表示正式运行时美术完成。当前运行时候选、精确覆盖与验收门槛分别见 [Runtime V2 素材画廊](../../RUNTIME-V2-ASSET-GALLERY.html)、[Runtime V2 覆盖状态](../../RUNTIME-V2-STATUS.md) 和 [游戏运行时素材契约](../../GAME-RUNTIME-ASSET-CONTRACT.md)；原型结构见 [manifest-complete.json](./manifest-complete.json) 与 [qa-complete.json](./qa-complete.json)。

审计日期：2026-08-11

基线：每套 **404 个资源题材**，见 `THREE-SCRIPTS-GAMEPLAY-ASSET-BUDGET.md`。统计单位是“题材”，不是 PNG/SVG 文件数；同一题材的格式、尺寸、方向、动画帧和状态变体不重复计数。

## 1. 结论

- 当前正式包有 **22 个逻辑输出、44 个正式文件**：22 PNG + 22 SVG，均已通过现有 QA。
- 两套四格道具图集拆格后，正式包实际承载 **28 个内容题材**：6 角色、6 有姓名单位、4 建筑、4 场景、8 道具。
- 按全局 **404 类别槽位口径**，其中 22 个剧情题材占 22 个槽位，当前槽位覆盖为 **22/404，槽位缺口 382**。6 套有姓名英雄单位不计入 40 个通用战斗母型。
- 按稳定 ID 与质量验收口径，这 22 个剧情槽位中 **19 个可直接完成目标、2 个需要轻变体、1 个“破官印”是基线外补充**。为补回被补充项占用的目标 ID，实际还需 **383 个新制 + 2 个轻变体 = 385 项生产工作**。
- `382` 回答“404 类别还空多少槽”，`385` 回答“达到完整目标还要执行多少项工作”，两者不可混用。完成后，素材库会有 404 个基线题材，外加破官印与 6 套有姓名英雄单位共 7 个补充题材。
