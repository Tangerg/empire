## 1. 核心提案

### 1.1 一句话梗概

> 大晟末年，河决、饥荒与徭役把淮上百姓逼入绝境。押运官粮的河工沈砺放走三百饥民，从此成为朝廷逃犯。他从一支不满百人的乡兵起家，历经义军分裂、江东立足、大泽水战、群雄争衡与北伐中原，最终推翻旧朝、建立新国；然而当天下初定，他必须决定，是用猜忌和屠刀确保江山不再分裂，还是建立一套连皇帝本人也必须受约束的新法。

### 1.2 主角成长命题

沈砺最初认为：

> 百姓挨饿，是因为粮食没有送到他们手里。

中期他相信：

> 只要把贪官和无能的君主赶下去，天下就会重新太平。

最终他必须明白：

> 乱世不只是坏人造成的，也是军队、土地、赋税和权力没有边界造成的。打下天下的人不能把天下当作自己的战利品。

### 1.3 核心主题

1. **天命与人事**：胜利者是否天然代表天命，还是天命只是后来写进史书的解释？
2. **饥饿与战争**：战争因饥荒爆发，也会制造更大的饥荒。
3. **军纪与人情**：士兵来自饥民，却不能以曾经受苦为理由伤害新的百姓。
4. **门第与才能**：旧门阀掌握治理知识，但不能因此永远垄断权力。
5. **功臣与皇权**：共同打天下的人应获得什么，又该如何交出军队？
6. **统一与地方**：结束割据需要中央权力，中央权力也可能重新制造压迫。
7. **历史与责任**：史书可以把失败写成罪名，却不能替活人免除选择的责任。

### 1.4 题材定位

本剧本采用架空东方历史，而非直接改编某一朝代。主要气质来源为：

- 元末式的饥荒、民变、南方立足、水战与北伐；
- 隋唐之际的门阀、精锐骑军、群雄并起与军功政治；
- 汉初的布衣联盟、异姓将领与开国封赏；
- 南北朝的寒门军人崛起和南北远征；
- 宋初“如何收束将领军权”的制度难题；
- 明初户籍、屯田、卫所、功臣猜忌与高压治理的阴影。

这些只提供历史结构，不照搬真实人物姓名、具体战役结果或单一王朝叙事。

## 2. 创作边界

### 2.1 保持东方历史质感

- 政治围绕粮、地、税、兵、户籍、漕运和官僚展开；
- 战争胜负往往由补给、河道、城防、民心和将领关系决定；
- 将军不会仅靠个人武力击败一整支军队；
- 农民军不天然正义，朝廷军也不全是恶人；
- 北方诸族拥有自己的政治与文化，不作为无人格的“蛮族”；
- 女性角色通过水军、医署、账房、情报和地方组织进入权力，而非套用现代身份口号；
- 登基不是故事自动完成，而是新一轮政治冲突的起点。

### 2.2 低奇幻原则

主线默认没有可验证的神仙、法术和复活。所谓异象均保留现实解释：

- 彗星可能是天命，也可能只是被各方利用的天象；
- 军师“呼风”来自长期观察水文和季风；
- 医官的奇效来自隔离、清洁和药物；
- 方士的预言来自情报网与模糊话术；
- 战场鼓舞、威慑和“军魂”以士气系统呈现。

如项目必须保留魔法职业，可将其改造成火器营、军医、军师、工匠和旗鼓手，不改变剧情世界观。

### 2.3 明确避免

- 不把主角写成天生真龙或隐藏皇族；
- 不用神谕证明他每次选择正确；
- 不把屠城、肃清和文字狱当作强者魅力；
- 不把所有旧官僚都写成腐败无能；
- 不把百姓只当烘托主角仁德的背景；
- 不用爱情替代政治冲突；
- 不让谋士拥有超自然的全知能力；
- 不把统一等同于所有问题已经解决；
- 不为了保住功臣情谊而假装私人军队没有割据风险。

## 3. 天下格局

### 3.1 大晟王朝

大晟立国二百七十余年。末期连续发生河决、旱灾、疫病和货币崩溃，朝廷为偿还北方战争军费，仍强征粮税与河工。

王朝并非突然腐烂，而是陷入一套互相强化的困局：

```text
边防失利
→ 加税与征兵
→ 农户逃亡
→ 税基减少
→ 地方豪强兼并土地
→ 朝廷更加依赖豪强和军镇
→ 中央失去控制
```

### 3.2 主要区域

| 区域 | 地理与经济 | 战略意义 |
| --- | --- | --- |
| 淮右 | 河网、堤坝、灾田与漕仓 | 主角故乡、民变起点 |
| 江东 | 稻米、盐场、手工业与大城 | 建立稳定根据地 |
| 云梦大泽 | 湖泊、芦苇、水寨与造船场 | 决定南方霸权的大水战 |
| 吴越 | 富庶城镇、海贸、士绅庄园 | 财富与地方自治冲突 |
| 荆襄 | 江汉要冲、山城与水陆枢纽 | 西进与北伐门户 |
| 关陇 | 关隘、牧场、旧军镇 | 精锐骑兵和旧门阀根基 |
| 中原 | 农田、运河、旧都与战乱平原 | 天下名义与粮运中心 |
| 燕云 | 长城、草原、互市与多族城镇 | 北方决战与长期边防 |

### 3.3 主要势力

#### 大晟朝廷

- 优点：仍有成熟官僚、仓储、驿路和治水知识；
- 问题：中央财政破产，命令依靠地方层层加码；
- 军事：禁军、厢军、门阀部曲、重弩和早期火器；
- 代表人物：裴昭、宰辅程肃。

#### 白炬军

以“开仓同食”为号召的民变联盟，内部包括饥民、矿工、盐徒、地方教团和野心家。

- 优点：动员力强、打破门第、得到灾民支持；
- 问题：缺乏统一军纪，部分首领以末日教义合理化杀戮；
- 军事：轻步兵、乡弓、盾车、地道和人海围城；
- 代表人物：顾重山、韩岳、沈砺。

#### 云梦水盟

控制大泽航路的船户、渔寨和水军联盟。

- 优点：水战、造船、火攻与水文经验；
- 问题：各寨只服自己的盟誓，长期参与盐运和劫掠；
- 代表人物：江照夜。

#### 楚王梁震

白炬军分裂后建立的强大政权，拥有最多兵力、最大的楼船和最激进的天命宣传。

- 优点：敢于打破旧秩序、军事动员极强；
- 问题：把人口和粮食都视为决战资源；
- 军事：巨舰、火船、重甲步兵、敢死队；
- 叙事作用：沈砺“以胜利为唯一尺度”道路的镜像。

#### 吴越行台

由商人、士绅和旧官共同维持的富庶自治政权。

- 优点：贸易、城市治理、民兵与财政；
- 问题：以秩序为名拒绝接纳流民，把税负转嫁给佃户；
- 代表人物：苏伯庸。

#### 大朔

控制燕云和中原北部的多族军政联盟。既有征服者，也吸纳大量原大晟官员与农户。

- 优点：骑军、驿站、跨族用人和北方贸易；
- 问题：不同族群法律不平等，军户负担沉重；
- 代表人物：乌延晟、阿勒坦。

## 4. 历史前情

### 4.1 河患与漕粮

十年前，大晟为恢复旧河道征发数十万河工。工程本身并非毫无意义，但官员为赶期限隐瞒地质风险，最终导致淮右决口。

沈砺的父亲死于决口，母亲死于次年疫病。他后来进入驿站做河运差役，学会看水位、路线、粮袋重量和官文漏洞。这些能力将成为他胜过门阀将领的第一批本领。

### 4.2 北方失衡

大晟为对抗大朔长期维持高额边军，却拖欠军饷。关陇门阀以私人部曲补足防线，逐渐拥有独立财政和任官权。

朝廷不能简单撤军，也无力继续供养。每一次增税都以真实边防需要为理由，构成本剧本“坏制度由合理决定累积而成”的基础。

### 4.3 白炬兴起

白炬原是灾民互助会，约定每家夜间点一盏白纸灯，表示有余粮可分。随着镇压加剧，白灯成为起义标记。

领袖顾重山把互助会组织成军队，但无法控制所有地方首领。白炬军既救济饥民，也发生过强征、报复和滥杀。

## 5. 核心角色

### 5.1 沈砺

22 岁登场，40 岁结束。河工之子、驿站粮运差役，后成为开国皇帝。

优势：

- 对粮道、地形和普通士卒生活有直觉；
- 愿意提拔不同出身的人；
- 战败后能迅速调整，不迷信面子；
- 善于把宏大目标拆成可执行的小事。

缺陷：

- 极度恐惧饥荒和失控，容易囤积权力；
- 把忠诚理解为经得住秘密考验；
- 越成功越不愿承认别人可以反对自己；
- 习惯记录每个人的过错，晚年可能把风险管理变成猜忌。

人物弧：放粮逃犯 → 义军小校 → 严明营主 → 江东统帅 → 天下之主 → 被自己建立的密探和军权包围的皇帝 → 接受制度约束或成为铁腕君主。

### 5.2 陆青禾

淮右药铺账房，沈砺的同乡。她能识字算账，早期负责伤员、粮册和流民登记，后来建立地方户籍与赈济体系。

她不是只负责劝主角仁慈。她也会作出冷酷决定，例如为了防疫封锁一座村庄、为了稳定粮价禁止军队免费放粮。

核心理念：

> 善政不是君主偶尔心软，而是普通人不必先遇见明君才能活下去。

最终她推动《开国约法》，要求赋税、征兵、审判和军队调动均有公开程序。

战斗定位：军医、后勤官、士气恢复与战场救护。

### 5.3 韩岳

铁匠出身，沈砺最早的生死兄弟。勇猛、直率、深受士卒拥戴，是白炬军中最具号召力的前锋将领。

他真心爱护部下，却逐渐把私人军队视为兄弟们用命换来的财产。开国后拒绝交兵，既因骄傲，也因沈砺秘密监视功臣的行为确实存在。

他的最终叛乱可以被避免，但不能靠友情对话。必须有公开审理、退役保障、军饷兑现和皇帝同样受约束的制度。

战斗定位：重装先锋、破阵、士卒号召。

### 5.4 裴昭

关陇门阀出身的大晟年轻将领，军事才能卓越。第一章是追捕沈砺的敌将，第二章因拒绝屠杀灾民被贬，第三章加入。

他代表旧制度中真实存在的能力、责任和傲慢。他相信没有长期训练的官僚和军官，农民军只会建立另一个暴政。

与沈砺的关系经历：敌对 → 相互认可 → 主从合作 → 对皇权边界的公开争论。

战斗定位：骑军指挥、预备队调度、以少击多。

### 5.5 江照夜

云梦水盟的船主之女，后成为大泽舰队主将。早期从事走私与劫漕，也救过大量被官军抛弃的灾民。

她不认为统一天然优于水寨自治。加入沈砺的条件是保留地方水务与船户议事权。

战斗定位：水军、火攻、舰船机动和天气判断。

### 5.6 萧慎

落第士人，曾为县吏，因揭发赈灾舞弊入狱。擅长律令、文书和敌方政治分析。

他主张用严法限制军队，却后期被沈砺提拔为密察司首任官员。权力使他逐渐相信秘密监控比公开审判更有效。

他不是纯粹奸臣，而是“为了防止乱世重来，愿意让所有人生活在被怀疑中”的制度化对手。

战斗定位：军师、情报、伏兵识破和敌军动摇。

### 5.7 阿勒坦

大朔边将之子，母亲是中原人。早期与北伐军交战，后因反对屠杀投降城镇而被自己的上级追杀。

他加入不是“归顺文明”，而是与沈砺签订互市、军户平等和部族自治条件。开国后若这些条件被撕毁，他会重新成为敌人。

战斗定位：草原轻骑、侦察、诱敌与长距离突袭。

### 5.8 顾重山

白炬军早期领袖，曾是灾区僧舍的护院。他救过沈砺，也相信只有神圣天命才能把分散饥民组织起来。

第二章中，他为维持白炬统一，纵容地方首领报复旧官和士绅。沈砺最终与他分道扬镳，但不会否认自己从他那里得到的一切。

### 5.9 梁震

楚王、大泽霸主。出身盐徒，与沈砺一样来自底层，却更相信只有压倒性胜利才能结束饥荒。

他是主角的镜像：同样理解百姓痛苦，同样善于用人，但把所有活人都当作未来太平的投入成本。

### 5.10 史官闻素

从第三章起随军的年轻史官。她为不同阵营记录战死者姓名，并不断发现官方战报与亲历事实的差距。

她不参加常规战斗，却承担“谁书写天命”的叙事线。结尾她可以接受御修国史，也可以保留不经皇帝审阅的《淮上实录》。

| 第五章 | 21～25 | 统一是征服还是建立可接受的秩序？ | 群雄平定，称王准备北伐 |
| 第六章 | 26～30 | 谁能代表天下与北方各族？ | 收复中原，建立新朝 |
| 第七章 | 31～35 | 打天下的功臣如何共同退出战争？ | 新法、铁腕或裂土三种开国结局 |

### 7.1 叙事递进

```text
一袋官粮
→ 一支乡兵
→ 一座城
→ 一片江南根据地
→ 南方霸权
→ 天下统一
→ 统一之后的权力边界
```

### 7.2 战争不跳过治理

每一章的胜利都必须产生下一章问题：

- 放粮救人造成逃犯与追兵；
- 起义扩张造成军纪失控；
- 占领城市造成粮价、治安和官员短缺；
- 大胜造成降兵、战俘和将领势力膨胀；
- 统一南方造成是否称王与北伐压力；
- 建国造成私兵、封赏、税制和继承冲突。

## 8. 战斗系统适配

### 8.1 兵种体系

| 类别 | 兵种 | 用途 |
| --- | --- | --- |
| 步军 | 刀盾卒、长枪阵、陌刀队 | 正面战线、反骑、破甲 |
| 远程 | 乡弓手、强弩营、神臂弩 | 压制、守城、反重甲 |
| 骑军 | 游骑、甲骑、边军斥候 | 侧击、追击、截粮 |
| 水军 | 艨艟、楼船兵、火船队 | 水面机动、接舷、火攻 |
| 工程 | 河工、架桥营、云梯队、炮石营 | 改造地形、攻城、修堤 |
| 火器 | 火铳手、火箭营、震天雷队 | 破阵、恐慌、有限弹药 |
| 支援 | 军医、旗鼓手、粮秣官 | 治疗、士气、补给 |
| 谋略 | 军师、斥候司、说客 | 伏兵、情报、招降、扰乱 |

### 8.2 核心战场资源

#### 士气

- 将领败退、粮车被夺、侧翼崩溃会降低士气；
- 士气低的单位可能溃退而非战死；
- 旗鼓、军纪和保护平民能够恢复士气；
- 敌军可以被击溃、招降，不要求全部击杀。

#### 粮秣

- 部分大型关卡拥有有限军粮；
- 行军、火器、重骑和长期围城消耗不同；
- 强征民粮能快速补给，却降低地方支持；
- 保护漕船、粮仓和屯田可影响后续关卡。

#### 地方支持

- 百姓提供向导、民船、隐藏道路和守城情报；
- 支持度不是抽象好感，来源于军纪、粮价、征发和兑现承诺；
- 一地支持高不代表另一地自动信任主角。

### 8.3 代表性地图机制

- 河堤决口与筑堤；
- 漕船护送与抢粮；
- 夜渡、浮桥和渡口争夺；
- 城墙、云梯、地道和内应；
- 湖面风向、火船与舰队接舷；
- 雨季泥泞与骑军机动；
- 北方草原视野、补水与诱敌；
- 都城巷战、宫门与多阵营军令。

### 8.4 武将系统

武将不作为一人杀百人的超人，而以以下方式体现价值：

- 指挥范围和阵形转换；
- 在溃退边缘稳住部队；
- 决定预备队投入时机；
- 与特定部队建立长期信任；
- 战前说服、战中招降和战后整编；
- 双将组合战法来自配合，而不是玄学羁绊。

## 9. 城镇、军营与时间流逝

### 9.1 移动营地

前两章以行军营地为主：

- 粮车：补给、军粮争执；
- 伤兵棚：人物后果和军医支线；
- 中军帐：任务与将领会议；
- 火头营：士卒日常；
- 书记案：战报、名单和选择记录。

### 9.2 江东都城

第三章后解锁临川作为长期基地：

- 枢密院：编组和武将任命；
- 户曹：屯田、征税和地方支持；
- 工曹：兵器、船只和攻城器械；
- 学馆：寒门与旧官员培养；
- 史馆：查看不同版本战报；
- 市井：观察政策如何影响物价和百姓。

### 9.3 时间表现

十八年不能只用字幕跳过。每次跨年应表现：

- 角色外貌、服装和称呼变化；
- 老兵退役、新兵加入；
- 曾经的难民成为农户、商人、官吏或盗匪；
- 城市从废墟到繁荣，也可能因征税再次衰败；
- 沈砺从与士卒同锅吃饭，逐渐隔着宫门听取奏报。

## 10. 选择与变量

### 10.1 四个全局倾向

| 倾向 | 主要来源 | 后果 |
| --- | --- | --- |
| 民生根基 | 赈粮、屯田、轻徭、保护生产 | 补给、地方援军、结局恢复力 |
| 军纪威信 | 约束劫掠、兑现军饷、公平赏罚 | 招降率、溃军控制、功臣信任 |
| 开放用人 | 吸纳降将、旧官、女性与多族人才 | 兵种、治理能力、门阀反弹 |
| 皇权集中 | 密探、临时军令、越过审判 | 行动效率、叛乱风险、最终结局 |

皇权集中不是纯负面值。前期适度集中能避免联盟瘫痪，过低也可能导致军阀割据；问题在于临时权力能否在战争结束后归还。

### 10.2 关键记录

- 是否放出第一批官粮；
- 是否惩罚劫掠自己家乡的义军；
- 是否接受裴昭及旧朝军官；
- 围城时选择强攻、困城或开粮道；
- 大泽火攻是否预留平民航道；
- 是否兑现水盟自治条件；
- 是否承认大朔降民平等；
- 是否让史官保留不利记录；
- 是否建立密察司以及授权范围；
- 是否按时支付韩岳部队军饷；
- 皇帝是否也接受公开审理。

### 10.3 分支控制

- 主线保持七章、35 图，控制制作量；
- 选择改变援军、投降、地图状态和人物结局；
- 功臣冲突通过长期变量累积，不由单一对话决定；
- 最终三路线共用都城地图，但目标和可用阵营不同；
- 不设置“所有人存活才是真结局”的单一完美答案。

## 11. 三种结局

### 11.1 推荐结局：约法定鼎

沈砺公布《开国约法》：

- 常税、征兵与徭役必须公开上限；
- 功臣私兵分期转为国家军队，士卒获得退役田与欠饷；
- 重罪必须公开审理，密察司无权直接定罪；
- 地方水利、互市和行会保留约定自治；
- 皇帝发动全国战争需取得枢密与户曹共同确认；
- 史馆保留未经皇帝删改的副本。

这不是现代民主制度，而是一套符合架空时代条件、能实际限制随意征发和秘密处决的开国规则。

沈砺仍是皇帝，但接受自己也可能被制度阻止。

### 11.2 铁鼎结局

沈砺以最快方式镇压功臣兵变，建立高度集中的皇权、军户和密察制度。短期内天下稳定、贪官受到严惩、北方防线坚固。

代价是大量功臣和地方自治被清除，史书只保留皇帝认可的版本。结尾年老的沈砺面对一张越来越长的疑犯名单，仍然相信再杀最后一批人就能真正安全。

### 11.3 裂土结局

沈砺拒绝流血，也拒绝建立能让各方交兵的中央制度，最终把土地和军队分封给功臣。

一代人内避免大清洗，却为下一轮诸侯战争埋下种子。尾声中孩子在新的界碑旁被征入不同军队。

### 11.4 结局原则

“约法定鼎”是主题完成度最高的路线，但仍有代价：改革缓慢、边防争执、功臣不满和地方反复。制度不是一次签字后的永久胜利。

## 12. 核心意象

- **粮袋**：从救命的一袋官粮，到天下赋税与军队供给；
- **河堤**：权力像治水，既需要集中行动，也必须允许分洪；
- **白灯**：灾民互助的起点，后来可能变成神圣权力的标志；
- **军旗**：最初代表共同活命，后来成为将领私人军队的所有权；
- **名册**：赈灾册、军功册、户籍册、密探名单和史书；
- **宫门**：战争结束后，主角与普通人之间逐渐增加的距离；
- **空碗**：衡量每一个宏大政策是否真正有意义。

开场是一只被官印封住的粮袋。

结尾是一间普通食肆。店主把新收的粮食盛进碗里，不知道皇帝今日在朝堂上作了什么决定，却知道今年的税额不会在半夜突然增加。

## 13. 制作风险与控制

### 13.1 与候选剧本 1 的区别

候选剧本 1 同样包含政治和领袖成长，但本剧本需要保持鲜明差异：

- 无魔法王冠和古代超自然网络；
- 冲突落在粮税、兵权、门阀、水利和户籍；
- 主角不是从军官到联盟领袖，而是从底层劳动者到开国皇帝；
- 最终威胁不是外在神器，而是开国集团自身的军权结构；
- 领袖成长允许更苦涩、甚至失败的结局。

### 13.2 地图资产

建议控制为五套主要资源：

1. 淮右村镇、河堤与灾田；
2. 江东城镇、农田和营寨；
3. 大泽水面、船只与芦苇；
4. 中原城池、运河和宫城；
5. 北方关隘、草原和雪地。

大型城池通过城外、城墙、坊市、官署复用组件，不为每座城制作完全独立资产。

### 13.3 历史叙事风险

- 避免用现代网络语言代替时代人物表达；
- 制度设计要从当时可用的文书、官署、盟誓和地方自治出发；
- 不把民族冲突简化成文明与野蛮；
- 不对屠城和肃清进行爽文化包装；
- 军事传奇必须同时表现补给与普通士卒代价；
- 结局不声称一纸约法解决封建时代全部矛盾。
