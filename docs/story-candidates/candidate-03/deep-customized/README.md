# 《布衣定鼎》深度定制版

本目录把原有 35 关历史战役大纲深化为可演出的章回剧本处理稿。原文件继续作为事实底稿，本目录负责人物生活、场景动作、对白、时间流逝与制作接口。

## 阅读顺序

1. [创作圣经](./00-creative-bible.md)：历史质感、人物弧、普通人回访线和写作边界
2. 七章处理稿：[淮上饥年](./01-famine-by-the-huai.md) · [白炬旗下](./02-under-the-white-torch.md) · [江东立足](./03-foothold-east-of-the-river.md) · [大泽决战](./04-battle-of-the-great-lake.md) · [群雄尽处](./05-where-the-warlords-end.md) · [北伐](./06-northern-expedition.md) · [开国之刃](./07-blade-of-the-founding-reign.md)
3. [人物声线](./08-character-voice.md)：人物声线、称谓变化和对白样稿
4. [静态素材清单](./09-static-assets.md)：角色、场景、道具、建筑、风格素材与现有资源映射
5. [连续性验收](./10-continuity-check.md)：十八年时间、粮册、军权、盟约与结局验收

## 素材目录

正式素材统一放在上一级 [`../assets`](../assets/) 中。本目录内的 `assets/` 只保留索引，不复制图片。

## 定制目标

- 把“放粮、起兵、夺城、称王、北伐、建国”写成连续因果，而非英雄履历
- 让百姓、河工、书吏、军户和降卒在多年后回到故事中
- 用粮价、名单、道路、口音、衣物和称谓表现十八年时间流逝
- 让沈砺的集权冲动从可理解的救灾习惯逐步长成，而非登基后突然黑化
- 让最终制度冲突与第一关的官粮、假账和无籍灾民逐项回扣
