# C02 Runtime V2 Batch-02：ImageGen 母图提示词

执行模式：built-in ImageGen。每次生成均把首批对应母图作为“仅供风格参考”的输入，不编辑、不复刻原主体。透明对象板使用统一 `#ff00ff` 键背景，落盘后通过官方 `remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill` 生成 RGBA 中间图；最终运行时素材由 `scripts/build_batch_02.py` 确定性切片。以下“通用方向 + 对应条目”构成实际提示词集合。

## 通用方向

- 用途：游戏运行时 HD 科幻像素素材；C02 磨损维修社会风格。
- 像素簇清晰；氧化钢、刮擦陶瓷、补丁织物、克制青蓝辉光、铁灰与锈红。
- 禁止文字、标签、水印、边框、摄影模糊、色条占位和纯换色变体。
- 透明板：背景必须完全均匀 `#ff00ff`，无地面、投影、渐变；主体不可含洋红。

## 单位板

### `combat-board-a`

严格 4×4。每行同一单位依次为 stand A、step A、stand B、step B，朝右、同基线：动力剑士（巨型反应堆动力剑）、共生卫士（根甲与活体盾）、沙地游骑（双足沙兽、风帆、钩枪）、悬浮枪骑（反重力小艇、长枪、青色推进器）。四类轮廓必须根本不同。

### `combat-board-b`

严格 4×4、四帧同序：潮鳍斥候（鳍披风、呼吸器、鱼叉枪）、长束狙击手（极长矩形束枪）、孢子射手（菌罐与膨大生化发射器）、星脉术士（陶瓷悬浮环与导电杖）。

### `mission-board-a`

严格 4×4、非战斗四帧：赫沙水务维护员（压力兜帽、扳手、软管背包）、接水居民（肩担双陶瓷桶）、赤砂镇儿童（小体型、围巾、雨量计）、远灯号货运船员（动力搬运架、货单板、夹具）。

### `mission-board-b`

严格 4×4、非战斗四帧：携卷铺与杂包的难民；乘坚固医疗移动椅、带呼吸罩和输液罐的病患；持铆接工具与线圈的船坞造船工；带热反射环与长灯杆的索勒热灯维护修士。

## 地形与交互物

### `terrain-board`

严格 4×2 正交顶视板：赫沙玻璃海、密封水路、索勒脆冰、热灯步道；涅瑞亚逆向洋流、维尔达菌床、凯隆列车站台、远灯号生活舱。每格材质和功能必须独立，连接类须呈现清楚通路母型。

### `structure-board`

严格 3×4；每行 normal、damaged、captured：星脉权限节点、潮锚控制台、重力切换台、水封过滤站。受损态必须有断管、裂壳、断环或露线；占领态必须改变核心夹具、屏幕与权限带，不能只加旗帜。

### `prop-board`

严格 4×2：陶瓷水罐、货箱、平台盾、巨根；过载节点、燃料氧气罐、冰裂、孢子囊。每个对象有独立战术轮廓。

## 图标板

### `equipment-board`

严格 4×2：反应堆动力剑；活体盾与藤甲；风帆鞍与钩枪；悬浮长枪与推进器；鱼叉枪与呼吸器；长束枪与瞄具；孢子炮与菌罐；导电杖与星脉环。缩到 32px 和灰度仍可区分。

### `skill-board`

严格 4×2：动力突击、救援冲刺、长束狙击、孢子射击；星脉降权、沙帆机动、潮线移动、共生再生。禁止共用徽章底板，按动作语义形成不同轮廓。

### `status-hud-board`

严格 4×2。上排状态：受控、隐蔽、过热、失温；下排 HUD：友军、敌军、主目标、危险区域。八项不得仅换色或复用同一徽章模板。

## FX

### `fx-board`

严格 4×4，每行四阶段：刃击（细斩线到金属碎屑）、爆破（压力闪光到余烬）、生化命中（孢子球到菌状飞溅）、真空破裂（压力裂口到收束空洞）。所有帧居中且不碰边。
