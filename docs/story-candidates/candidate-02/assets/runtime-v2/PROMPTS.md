# 《群星熄灭之前》运行时素材 V2：母图提示词记录

本批全部母图由 built-in ImageGen 生成并原样保存在 `masters/`。透明素材统一使用纯洋红色键背景，再经官方 `remove_chroma_key.py` 转成 RGBA；运行时 PNG 由 `scripts/build_runtime_v2.py` 确定性切片、缩放、限色与校验。母图仅作创作来源，不代表 `runtimeReady`。

## 通用美术方向

- 高细节 HD 科幻像素画，清晰像素簇，禁止模糊、矢量扁平图标、文字、水印和摄影写实。
- 与现有 C02 素材一致：氧化钢、磨损陶瓷、补丁织物、克制的青蓝辉光、锈红与铁灰，维修社会而非豪华舰队。
- 透明对象使用均匀 `#ff00ff` 键背景；对象之间留足安全间距，不接触画布边缘。
