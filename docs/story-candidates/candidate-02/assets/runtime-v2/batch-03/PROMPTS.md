# C02 Runtime V2 Batch-03：ImageGen 母图提示词

执行模式：built-in ImageGen。七次生成均以 Batch-02 战斗板作为“仅供风格参考”的输入，不编辑或复刻原主体。实际提示词由下列通用约束与对应动作板条目组成。生成结果原样保存在 `masters/*-master.png`；随后使用官方 `remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill` 生成 `*-alpha.png`，再由 `scripts/build_batch_03.py` 确定性切片。

## 通用约束

- 严格 4 列×4 行；每行是同一匿名战斗单位的 stand A、step A、stand B、step B，全部朝右、同装备、同光照、同脚底基线。
- HD 磨损科幻像素画：清晰像素簇、氧化钢、刮擦陶瓷、补丁织物、克制青蓝与锈红。
- 背景必须为完全均匀的 `#ff00ff`；无地面、阴影、渐变、文字、标签、边框、水印；主体不得含洋红。
- 四行必须依靠体型、武器、工具、机器人、载具或伴兽形成独立轮廓，禁止仅换色。
