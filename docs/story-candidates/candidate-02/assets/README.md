# 《群星熄灭之前》HD-2D 像素素材包

本包把剧本的“人工太阳、五界共同决定与死者回声”转译为彩色但不洁净的 science-fantasy 像素系统。角色和设备是可维修、可拼补的工作物；古代设施统一使用三角星脉纹，HD-2D 光效只强化星脉、雨与人造恒星，不取代像素主体。

## 视觉 DNA

- 核心形状：三角星脉、圆环、舱门、滴水管线；圆环代表稳定也代表循环。
- 核心材质：风蚀陶瓷、磨砂聚合物、补丁织物、透明水管、活体角枝。
- 色彩关系：赫沙铁红和赭黄是生活基底，青色只表示可用星脉，珊瑚红表示被挪用/过载，人造太阳使用不自然的白金。
- 科技原则：没有无缘由的霓虹；每个发光像素必须是能源、权限、维修灯或意识回声。
- 世界统一：六个世界材质可以不同，但所有古代设施必须重复同一三角形节点结构。

完整色值见 [style/tokens.json](./style/tokens.json)，可视色板见 [style/palette.svg](./style/palette.svg)。低细节首稿已整体移入 `draft-v1/`，仅保留为剧本覆盖和构图草案，不作为正式素材。

生产前覆盖与缺口审计见 [PRODUCTION-GAP.md](./PRODUCTION-GAP.md)。下述扩展包只登记 382 个题材槽位原型，不等于 382 项运行时美术已经完成。可预览的运行时候选、精确覆盖与验收门槛分别见 [Runtime V2 素材画廊](../../RUNTIME-V2-ASSET-GALLERY.html)、[Runtime V2 覆盖状态](../../RUNTIME-V2-STATUS.md) 和 [游戏运行时素材契约](../../GAME-RUNTIME-ASSET-CONTRACT.md)。

## 接入约定

- 单位图集从左到右为站立 A、踏步 A、站立 B、踏步 B；整图 `128×48`，每帧 `32×48`。
- 道具图集整图 `192×48`，按横向四格切分，每格 `48×48`；不要在导入时做平滑缩放。
- 场景分组为 `background`、`midground`、`foreground`、`hd2d-fx`、`high-detail-pixels`。关掉 `hd2d-fx` 后仍保留全部叙事对象。
- 星脉青光不可作为普通阵营换色；阵营色只改织物、护甲面板和小面积识别灯。
- 同一古代设施在任何行星都必须保留三角节点比例，允许材质风化但不改变底层结构。
- 环境动画建议使用整数像素位移：雨 `2 px/帧`，维护灯 4 帧循环，水位变化以整块遮罩切换。
