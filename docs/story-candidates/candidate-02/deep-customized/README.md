# 《群星熄灭之前》深度定制版

本目录把原有星系悬疑与 35 关大纲深化为可演出的章节处理稿。原文件保留为事实底稿，本目录只记录定制后的叙事层和生产层内容。

## 阅读顺序

1. [创作圣经](./00-creative-bible.md)：悬疑节奏、世界文化与人物弧总控
2. 七章处理稿：[沙海之雨](./01-rain-over-the-sand-sea.md) · [寂静天空](./02-silent-sky.md) · [冰月遗民](./03-heirs-of-the-ice-moon.md) · [环城谎言](./04-lie-of-the-ring-city.md) · [墓星回声](./05-echoes-of-the-tomb-world.md) · [五界战争](./06-war-of-five-worlds.md) · [群星熄灭之前](./07-before-the-stars-go-dark.md)
3. [人物声线](./08-character-voice.md)：小队声线、关系和飞船日常
4. [静态素材清单](./09-static-assets.md)：角色、场景、道具、建筑、风格素材与现有资源映射
5. [连续性验收](./10-continuity-check.md)：线索、倒计时、权限和结局条件验收

## 素材目录

正式素材统一放在上一级 `../assets` 中。本目录内的 `assets/` 只保留索引，不复制图片。

## 定制目标

- 保留“寂潮是被保存却无权退出的死者”这一原创核心
- 让五个世界拥有生活方式、内部矛盾和视觉语法，而不是五套地形皮肤
- 让每次真相揭示先改变人物关系，再改变百科知识
- 增加远灯号的日常、争吵、食物、维修和私人空间
- 让最终方案由前期可见的维护实践逐步长成，而非终章突然出现技术答案
