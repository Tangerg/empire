# 安排《群星熄灭之前》的后续素材生产

下一阶段不再增加战斗单位。生产重点转向第一张真实星际关卡，并验证道路、水道、设施、载具、护盾和生化敌人在同屏时保持可读。

## P0 完成赫沙雨塔关卡

P0 把赫沙首章升级为可复用的生产模板：

1. 接入赤砂、玻璃海、密封水路和雨塔周边地形
2. 接入雨塔、星脉节点、水站、货运终端和野战诊所
3. 接入星盾兵、轨步枪兵、维修工程师、沙地游骑与治安机器人
4. 接入护盾、轨击、维修火花和沙雨特效
5. 输出无程序占位图的真实关卡截图

## P1 补足五界玩法资源

P1 为六个世界建立可重复使用的地图语言：

- 任务单位从 8 补到 24
- 阵营套件从 0 补到 12
- 地形从 16 补到 32
- 交互设施从 6 补到 24
- 战场物件从 8 补到 32
- 建立赫沙、索勒、涅瑞亚、维尔达、凯隆和厄客的环境变体

## P2 补足系统与叙事资源

P2 支撑完整星际战役：

- 叙事静态图补到 80
- 装备与技能分别补到 48
- 状态与特效分别补到 24
- 界面标记补到 16
- 建立星图、舰船舱室、伙伴事件、章节封面和多结局清单

## 每批交付完整文件

每批素材必须包含以下文件：

- 独立的 `manifest-runtime-v2-bNN.json`
- 对应的 `qa-runtime-v2-bNN.json`
- 原创母图、最终提示词和可复现处理脚本
- 1× 预览与真实关卡截图
- 不覆盖旧批次的版本化 PNG 与 SVG
