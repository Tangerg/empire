# 按《群星熄灭之前》的运行时规格交付

本页定义《群星熄灭之前》可以直接进入战棋引擎的文件规格。概念图、母图、原型 atlas 和大尺寸剧情样包不能代替运行时交付。

## 使用统一文件基线

游戏以 `32×32` 为基础棋盘格。PNG 是运行时格式，SVG 只用于审阅与可复现导出。所有坐标和缩放使用整数，渲染采用 nearest-neighbor。

| 类型 | 必须交付的规格 |
| --- | --- |
| 标准单位 | 四帧横排，单帧 `32×48`，锚点 `(16,47)` |
| 大型单位 | 单帧 `64×48`、`64×64` 或 `96×64`，声明足迹、锚点与层级 |
| 非连接地形 | 单格 `32×32`，至少 4 个稳定变体 |
| 连接地形 | 单格 `32×32`，提供北、东、南、西 16 个邻接掩码 |
| 设施 | 声明足迹与热区，至少交付正常、受损、占领三态 |
| 装备与技能 | 源单元 `32×32`，实机显示 24 至 32 像素 |
| 状态与界面标记 | 源单元 `24×24` 或 `32×32`，保持 1 至 2 像素最小线宽 |
| 特效 | 单元 `32×32` 或 `64×64`，使用 4、6 或 8 帧横排 |
| 剧情场景 | `256×144` 不透明 PNG，底部 32 像素避开关键证据 |

## 保持单位锚点稳定

单位源图默认朝右，朝左由游戏水平镜像。每帧脚底必须落在同一基线，武器、头部、载具和生化部件不能被裁切。透明单位不带地面、外框或烘焙阴影。

## 制作可拼接地形

水道、轨道、能源管线、舱室走道与菌床边界使用 16 个邻接掩码。四边必须逐像素无缝。护盾、孢子污染、失重与过载层独立于基础地形。

## 定义设施状态

雨塔、星脉节点、水站、舱门和重力台至少包含 `normal`、`damaged` 与 `captured`。可关闭设施增加 `disabled`，可摧毁目标增加 `destroyed`。阵营灯光放在独立遮罩层。

## 声明清单字段

每项运行时素材必须声明稳定 `contentId`、精确 `topicId`、类别、PNG 路径、画布尺寸、帧数与锚点。大型单位和设施还要声明 `footprint` 与 `zOrder`。特效还要声明 `fps`、`blendMode` 和 `loop`。

## 保持本剧本风格

所有运行时素材以 [`reference/art-direction-map.png`](./reference/art-direction-map.png) 为唯一视觉基准。青色只表达水、护盾或可用星脉；橙色表达热能与弹道；紫色表达寂潮与生化污染。发光区域不能淹没轮廓和材质。
