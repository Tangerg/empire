# 正史之外分支附录

正文采用“群星共鸣”。本附录保留另外两种结局的完整因果方向，但不把它们插回正文制造并列菜单。采用分支时，应从第五、六章的人物边界开始改写，而不是只更换弥光核心中的最后指令。

## 第七次黎明

分歧发生在五界广播之后。米拉把公开真相造成的混乱理解为公开得还不够彻底，罗安则进一步相信只有一次带警告、带存档的归零能结束寂潮。两人的师徒关系因重新合作而暂时修复，也使其他世界的退出权再次被置于“总体存续”之后。

第六章中，五界代表可以审阅归零方案，却无法否决；死者、机械与生态网络被承诺在下一周期恢复。终章执行第七次修改。灾害停止，许多城市以更好的预案进入新周期，同时有数十亿当代生命被结束，且无人能证明恢复者仍是原来的人。

最后画面应是岚柯的金属杯被重新制造得毫无凹痕。米拉认得它，岚柯却不记得为何凹口原本总朝外。不能以明亮黎明掩去这种损失。

## 逐光者

分歧从凯隆百分之二名单开始。米拉没有彻底拆掉评分逻辑，而是将它改成更透明、更少裙带的撤离制度。罗安反对逃亡会引寂潮追踪，赫洛则把远灯号改成第一艘公开载员舰。

第六章不再建立五界最低星约，而是争夺燃料、胚胎库、档案和航路。每多带一套文化档案，就可能少一张病床；每个公开标准仍会把某些具体家庭留在地面。伊娅可选择只带部分记忆，塔洛斯可拒绝被当作机械文明备份，珂塔不能代表整个维尔达随船离开。

终章中少数舰队逃离，寂潮信号仍可能跟随。最后画面是远灯号公开载员墙：上面不仅有登船者姓名，也保留未登船者与被拒理由。新的星空不是胜利证明，只是更长的风险。

## 不随分支消失的代价

- 罗安的照顾与控制始终来自同一套风险意识，不能突然黑化。
- 伊娅拥有关闭、删减和不被持续观看的权利。
- 任何归零、保存或撤离都必须写到水、床位、能源、家庭与人格连续性。
- “群星共鸣”也不是零牺牲方案；它失去大量便利，并承担长期维护与地方拒绝。
