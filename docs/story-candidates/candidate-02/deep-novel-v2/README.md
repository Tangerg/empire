# 《群星熄灭之前》小说化深度版

本目录将五界战役改写为七章连续长篇小说。正文采用第三人称近距离视角，以米拉为主要视点；仅在她不在场、且角色必须独立作出决定时，短暂进入罗安、赫洛、塔洛斯、伊娅等人的有限视点。

主线采用“群星共鸣”正史。归零与逐光路线保留到分支附录，不在正文中把关键时刻拆成并列选项。

七章小说正文合计约 9.46 万字；设定总控、分支与素材接口不计入正文规模。

## 文体约定

- 不使用关卡号、战斗目标、触发条件或角色名加冒号的剧本格式。
- 技术与术式只写人物眼前能够操作、失去或承担的部分。
- 小队亲密不靠所有人意见一致，而靠共用空间、互相记住限制并允许退出。
- 每次解决星系级问题，都要落回一杯水、一张床、一道门或一份载员名单。
