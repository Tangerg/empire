# 三套剧本可玩资源目标预算与扩充方案

本方案把“剧情静态图”和“可玩资源”拆开计算。每套剧本的战斗单位控制在 40 个左右，但地形、任务单位、交互结构、装备、技能、状态、特效和 UI 必须同步扩充，否则只是角色数量变多，战场玩法不会真正丰富。

本文定义目标体量，不代表 1212 个题材已经成为正式游戏美术。当前可预览的运行时候选、精确覆盖与验收门槛分别见 [Runtime V2 素材画廊](./RUNTIME-V2-ASSET-GALLERY.html)、[Runtime V2 覆盖状态](./RUNTIME-V2-STATUS.md) 和 [游戏运行时素材契约](./GAME-RUNTIME-ASSET-CONTRACT.md)。

当前正式素材与目标之间的精确缺口、可复用代码占位和 P0 补全批次见 [`ASSET-LIBRARY-GAP-AUDIT.md`](./ASSET-LIBRARY-GAP-AUDIT.md)。

## 八、每套 48 组武器与装备

统一采用“40 个兵种主装备 + 8 个共享战术装备”：

- 40 个兵种各有一组主武器 / 职业工具。
- 8 个共享装备覆盖治疗、工程、侦察、补给、反大型、抗状态、机动和任务交互。
- 每组建议包含主物件、副手、弹药 / 能源、阵营标识四格。
- 同一机制可复用数值，但三套剧本的材料、持握方式和视觉语法必须不同。

## 十三、生产顺序

1. 先完成每套 12 个 P0 战斗单位、12 组核心地形、8 个交互结构和基础 HUD。
2. 同步制作护送、工程、医疗、行政四类任务单位，确保地图能做出不同目标。
3. 再补装备、技能、状态和 FX，让兵种差异真正进入操作反馈。
4. 最后展开 P1/P2 单位、完整地形、装饰、阵营状态和 80 张剧情静态图。

衡量“资源丰富”的标准不是文件数，而是玩家能否通过轮廓认出单位、通过地图看懂规则、通过物件发现替代路线，并在不同剧本中获得不同的战术节奏。
