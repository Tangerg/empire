# 三套剧本素材库现状、缺口与补全总清单

> **状态更新（2026-08-11）：** 1146 个缺口已建立题材 ID、atlas 槽位与原型图，但扩展图的程序化风格与原 HD 素材不一致，已降级为 `prototype`，不算正式美术完成。当前正按 [游戏素材契约](./GAME-RUNTIME-ASSET-CONTRACT.md) 制作可实际接入引擎的 V2；原型结构见 [题材覆盖交付](./COMPLETE-ASSET-DELIVERY.md)。

审计范围：三套剧本在补产前的正式 `assets/`、单套与全局 manifest、QA、剧情静态清单、40 单位清单以及每套 404 个可玩资源题材预算。

## 一、结论

当前正式素材质量合格，但覆盖面仍属于“剧情视觉样包”，还不是完整游戏素材库。

- 三套各有 22 个正式逻辑资产，合计 66 个 PNG/SVG 资产对、132 个正式输出文件。
- 每套结构完全一致：6 头像、6 有名角色四帧单位、4 建筑、4 场景、2 套四格道具。
- 6 套道具图集实际包含 24 个独立道具，因此现有正式内容可换算为 84 个可用图像主体；其中 18 个有名角色单位图集属于英雄变体，不占“40 个通用战斗单位母型”名额。
- 完整目标为三套各 404 个、合计 1212 个资源题材；按不重复的严格槽位口径当前覆盖 66 个、约 5.4%，仍缺 1146 个题材。
- 当前缺口最大的不是剧情人物，而是通用战斗单位、平民/任务单位、地形、交互结构、战场物件、装备、技能、状态、FX 和阵营化 HUD。
- 现有处理、manifest 和 QA 流程只完整支持头像、单位四帧、建筑、剧情场景、道具四格五种类型，新资源类型的生产规范也必须同步补齐。

## 五、当前生产流程还缺的能力

### 1. Manifest 类型

当前全局构建只识别：`portrait`、`unit-sheet`、`architecture`、`scene`、`prop-sheet`。

需要增加：

- `terrain-tileset`
- `structure-sheet`
- `battle-prop-sheet`
- `equipment-sheet`
- `skill-icons`
- `status-icons`
- `fx-sheet`
- `hud-atlas`
- `faction-kit`
- `mission-unit-sheet`

### 2. 图像处理模式

当前处理工具只有 `single`、`sheet`、`scene` 三种模式。需要补：

- Tile atlas：连边、转角、边缘扩展和无缝性检查
- 多状态结构：正常、占领、受损、修复 / 失控
- 图标 atlas：固定格、留白、安全区和小尺寸可读性
- FX sheet：帧序、混合模式、锚点和循环规则
- 多格大型单位：占格、部位、操作员和受损态

### 3. 运行时元数据

新资源不能只交图片，还需要：

- 枢轴点、脚底线、朝向和动画帧序
- 建筑足迹、阻挡、碰撞体和可攻击部位
- Tile 连边掩码、地形高度和覆盖层兼容性
- 图标语义 ID、禁用态、冷却态和阵营着色规则
- FX 锚点、层级、持续时间、循环和混合模式

### 4. QA

需要在现有尺寸、颜色、透明、色键、XML 和 PNG/SVG 像素一致性检查基础上增加：

- atlas 每格非空、顺序和安全边距
- Tile 连边与无缝拼接截图
- 多状态结构尺寸、锚点和足迹一致
- FX 帧数、循环首尾和透明残留
- 16×16 / 24×24 图标的实际可读性检查
- manifest 路径、语义 ID 和资源引用完整性

## 六、建议的均衡 P0 补全包

这个全局包按每套相同数量分配，便于并行排产。三份分剧本报告另按章节依赖给出更细的 P0/P1/P2 切分，两者用途不同：全局表控制投入均衡，分剧本表控制具体先后。

P0 不先追求把 1146 个缺口一次画完，而是先让三套都能组成一个视觉完整、目标多样的可玩切片。

### P0 完成标准

- 每套至少能构成前线、机动、远程、治疗、工程、支援六类队伍。
- 每套至少有护送、撤离、维修、占领、破坏、救援六类可视化任务目标。
- 每套至少有一组地形互动和一组结构状态变化，而不是换背景作战。
- 单位、技能、状态、目标和 HUD 能在同一画面内清楚对应。
- 所有 P0 正式资源进入单套 manifest、全局 manifest、画廊和 QA。

## 七、复用与避免重复生产

- 6 个现有有名角色单位可作为各自职业的轮廓和颜色标杆，但通用兵种必须去除英雄专属细节。
- 4 个现有建筑可拆出材质、门窗、旗位和状态色，不直接充当所有交互结构。
- 两套道具图集的 8 个格可复用视觉母题并裁切为 UI 参考；只有补齐独立规格、语义索引和 QA 后才可占装备 / 目标槽位，不能与剧情静态题材重复记账。
- 现有 17 个代码 UI 图标保留语义，不照搬视觉；三套分别重画主题皮肤。
- 通用状态和结构规则可跨主题复用，图片、名称和材质按剧本替换。
- 场景中的雨、火、灯光和水面反射已经烘焙，只能作为 FX 参考，不能直接提取为可开关效果。
