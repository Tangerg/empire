# 棚顶 UV 不透明边缘修正建议

范围：原 PNG 像素只读、Python/Numpy 数值扫描；无图像修改、生产修改或引擎/GUI操作。

原图：barracks-front-lean-to-v2-candidate.png，1070×1470。
原 UV：[[115,391],[496,127],[947,383],[559,655]]。

用凸四边形与每个单位纹素方格的分离轴相交测试，保守纳入触及边界的纹素：原UV覆盖221270个方格，仅(218,318) alpha239/255=0.9372549低于opaque .96（8bit至少245），位于左上斜边。与writer fresh DLL错误位置完全相同。它不是深度、脚点或polygon漏洞，是原UV采样包络擦到半透明素材边。

旧TexturedProp每三角24步重心粗采样会漏掉这一个触边纹素。old-coarse-grid-check.json 对四角两种对角划分均保留数值结果；这不是替代Godot正式全纹素验证。
