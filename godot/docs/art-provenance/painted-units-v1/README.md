# Painted C07 figures, 2026-10-27

These original transparent PNGs were generated with the built-in image generation tool for Empire. They replace the 12 appearances actually present in C07; shared generic bindings also affect earlier scenes. This is not a claim that the whole campaign's art has been redrawn. Existing gameplay identity, positions, collision, stats, frame roles and turn rules remain canonical and unchanged.

The native selected-assets manifest owns runtime source regions, per-frame foot contacts and presentation scale. Registration-review.json records the measurement process, not a second runtime source. Four unequal regions preserve spears/flags/bows instead of clipping at assumed equal columns. PNG pixels are untouched. Each local foot anchor follows planted boot/paw contact, not the whole silhouette center; body height excludes raised weapons and flags. Infantry target 35 map units, mounted figure 40, reviewed in the real C07 scene. Linear sampling is used for these downscaled painted figures; legacy pixel sprites retain their existing sampling.

Hero and five infantry prompts are retained alongside this note. The three shield/rider/mage generation briefs used the same requirements: original warm painterly tactical-game cutouts, elevated 45-degree three-quarter camera, facing down-right, four poses (idle / walk-a / attack / walk-b), transparent background, no floor, no halo, no baked contact shadow, no UI/text, full weapon visibility. Shield identity: steel helmet, muted blue armor, cream rectangular shield and short spear. Rider identity: leather-clad lancer on gray wolf. Mage identity: dark-haired armored sword-and-fire combat caster. These are generation-brief summaries, not a claim of an exact prompt transcript.

Known limitation: several walk-a/b candidates vary arms and boots without fully alternating the leg phase. They are usable posed motion frames, not a full newly authored walk cycle. Runtime timing and frame-role behavior are unchanged. Source low-alpha edge noise is preserved, not hidden by postprocessing. Review at actual rendering scale and validate alpha-aware picking after every re-registration.
