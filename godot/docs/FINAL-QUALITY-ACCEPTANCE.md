# Native engineering acceptance

## Contracts and owners

The six reproduced Core defects are repaired at their owners: resolved plugin
substitution and closed installation contexts, immutable/detached catalog reads,
entity health and aggregate relocation/allegiance, composed disposition admission,
and handler-owned effect payload validation. Live transfer rejects detached
aliases and duplicate commander attachments before any mutation. The capability
map in `docs/engine-capabilities.md` names these owners.

Consumer-owned ports replace loose service lists; dependencies precede subjects
and event channels are last. Library resource defaults are explicit at composition.
`BattleEngine` is generic, `GrayFlagCampaignPolicy` is campaign-specific, and
renderer names describe their responsibility rather than migration prototypes.
No obsolete API aliases or runtime conversion layer remain for these changes.

Both new and restored sessions receive the same composed event presenter registry.
The actual screen regression dispatches a resource-changing turn and observes a
custom presenter through both paths. Both construction paths passed through the actual native battle screen.

The official SDK whitespace formatter is configured in `.editorconfig` and exposed
as `bash tools/godot/format-native.sh --check`; `verify-native.sh` calls it.
Source UID/import companions are tracked; caches and the identified scratch probes
are not release source. Formatting is not a substitute for the ownership review.

## Localization and state

Native JSON owns semantic structure/identities; the Simplified Chinese PO owns
shipped wording. Story, choices, menu, staging, HUD, refusals, objective progress,
conclusions, summaries, content names/hints and semantic combat modifiers resolve
through explicitly composed presenters. Missing authored mappings fail explicitly.
Developer diagnostics and asset provenance are not player-facing text catalogs.

The Core owns semantic objective facts and one conclusion. Ordered creation events
carry detached identity facts so a transient unit can be described after removal.
Translations cannot advance gameplay. Native save/replay schema 3 hashes every
serialized field; application schema 3 refuses old shapes without deleting or
automatically overwriting existing saves. No prose stripping or digest exclusions
are used to manufacture historical equality.

## Evidence and limits

The final API Core build, all independent shipped-level native save/replays,
opening unchanged-gameplay comparison and external public-assembly content/outcome
checks passed. Actual headless battle, result and navigation scenes passed with
clean process teardown. The formatter passed on a clean extracted indexed source
tree and rejected a deliberate whitespace violation. Source UID/import companions
passed the indexed metadata guard. The first current Linux export exposed a real
asset-discovery defect: the editor indexed a transient Core obj sourcelink file.
Core and its standalone tests now have .gdignore boundaries; they are compiled by
project references, not Godot resources. The corrected Linux export passed from an exported-only directory with no SDK,
source checkout, or oracle fixtures on PATH. It loaded current translations/assets
and exercised real story/choice/battle/move/save/load/restart/camp flow, rejected
invalid diagnostic requests, preserved an existing sentinel save, and exited cleanly.

The current aggregate has one canonical Core project owner. Separate external
consumer projects protect accessibility boundaries. Twelve historical source-v1
oracle/mutation runners remain outside current acceptance; their isolated source
substitution is not a second production engine. Rework a runner and its mutation
mechanism together if reactivated, rather than introducing a new framework.

Manual window input/visual acceptance remains blocked by the cloud input provider.
Actual headless Godot scene checks are functional evidence, not manual acceptance.
macOS launch/signing/notarization are unverified. Nine recovered levels lack authored
scenery, other themes/editor are outside the GrayFlag-first milestone, and independent
level replays do not prove a complete victorious carried-state campaign route.
