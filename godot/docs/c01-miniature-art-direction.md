# C01 微缩场景美术方向与验收

状态：重制方向说明，不代表素材、玩法或性能已经验收。C01可以重写空间、素材与交互契约，不以旧C01图、尺寸、坐标或存档兼容为设计目标。其他关卡与战役承接仍需明确隔离和验证。

## 一张能玩的微缩场景

像精心制作、统一布光的历史村镇微缩模型，而不是低精度多边形散件、草坪上的建筑贴纸或一张不能操作的概念画。原创老石墙、木构、瓦屋与人物共享同一材质尺度、光向和镜头语言。场景的大形先形成近景工作院、中景市场与远景街屋的连续空间，再加入有限生活痕迹。不要复制参考作品的建筑、人物、图标或界面。

第一眼顺序：当前行动人物与目标 → 街口/坡口 → 院落与建筑群 → 远景。连排屋与挡土墙负责围合空间，铺地和门洞负责解释通路。不是每格填满物件，也不是用无功能草地拉开距离。地图大小由有效决策与镜头可读性决定。

## 统一光照与材料

- 一套固定环境光：画面左上暖日光，冷蓝灰天空补光，接触阴影中性偏冷；屋檐下面保留木梁与门洞，不压成纯黑。跨镜头移动不得改变光向或整体曝光。
- 老石主色采用低饱和暖灰/沙灰，阴面转冷灰；瓦片用炭紫灰和少量旧陶红；木构深褐，金属只在刃口/铆钉有有限高光。草与苔藓不能比目标、人物或门框更亮。
- 同类材料共享石块、瓦片、木纹的视觉尺寸。墙面大明暗、磨损带先于裂纹与苔点。默认战术缩放看不清的小颗粒应被合并，而不是锐化成闪点。
- 阴影遵循实际脚点和高度，避免同时绘入一块黑影再叠一块黑影。屋体、人物、植被不允许各自不同的摄影棚光；远景降低对比而非蒙一层固定黑罩。
- 所有纹理边缘检验透明底、亮底、暗底：无白边、黑边、彩色溢出。透明材质外圈不得留下半透明光雾。不要靠放大阴影掩盖悬空脚。

## 几何、尺度与镜头

先统一相机、真实地面、人物尺度，再定建筑；不要为迁就单张生成图扭曲路网。使用经验证的原生投影/真实几何定位；不可用美术文件另造高度、可走性、阵营或占领状态。若改为新的渲染方案，明确替换旧的事实投影路径，而非叠加第二套逻辑。

- 建筑基座与真实不可走范围一致；高低台交界使用真实分层基础。连续屋檐可以跨接视觉，实心地基不能跨越合法街口。只有真实通路才画可进入门洞、台阶或桥。
- 角色与门洞用同一比例。作为首轮检查目标，默认960×640下普通角色头脚高约32–48屏幕像素、可交互门洞可辨宽约16像素以上；这是需实机校准的目标，不是既有承诺，更不能为达标侵占邻格。
- 比例硬约束：同一落脚平面、同一镜头下，用普通站立士兵（不含举起的武器/旗杆）作尺；日常门洞净高先定为士兵身高的1.1–1.5倍，市场主入口净宽至少容纳两名角色的可读肩宽且对应真实合法通道。不能在不同素材里让同一人忽大忽小；夸张巨门若是剧情地标，须明确为例外并重新审图，不静默改变全局比例。
- 诊断时固定同一镜头、曝光、角色与脚点，分别留纯哑光/中性材质版和最终材质版。哑光版检查体量、脚锚、坡口和遮挡，材质版检查光向、反差、闪点与透明边；两张不能同时换相机或物件来掩盖比例问题。此为建议取证流程，不宣称当前已实现切换功能。
- 关键坡口至少能分辨两侧边界、上下落脚与相邻人物。遮挡必须同时解决看得见、选得到、预测读得懂，不能只做鼠标穿透后让路径藏在屋顶下。
- 前景建筑保持较低檐线；远景可更高，但不能遮住唯一通路。取消选择后仍能读懂地形。不得要求玩家长期打开网格才能知道哪些地方能走。
- 960×640为最低真实验收尺寸，1180宽为复核尺寸。默认镜头须能找到主队、任务方向和第一处坡口；拖图后仍可定位。相机与HUD安全区一起设计，禁止为了漂亮截图临时把镜头移到不可用状态。

## 人物、动作与反馈

人物采用与场景一致的微缩绘制语言：清楚的头、肩、武器与脚底轮廓，衣料/皮革/金属分材质，避免高锐度像素人站在柔焦写实背景上。阵营以轮廓、旗记与有限色带区分，不只依赖红绿。伤残、已行动和选中反馈来自实际战斗状态。

待机克制，走路有明确落脚；攻击/施法包含准备、释放、命中、恢复，伤害结算与现有规则时点一致。魔法可以华丽，但不能持续遮住目标血量、命中格或下一步通路。摄像机震动、闪白和拖尾必须有明确上限与减弱设置设计，不能以表演代替预测信息。

## 原创HUD与图标

HUD延续微缩场景的温暖纸、暗木和旧铜语汇，但主体是低噪声、高可读信息面，不做厚金框舞台。图标自行绘制统一笔画/外轮廓：移动、攻击、施法、待机、占领各有独立形状；附文字或提示，不照搬现成游戏符号。

- 常驻只保留回合/阵营、关键资源、任务摘要、当前单位与结束回合。剧情长文与完整属性可展开，不常驻遮屋。
- 文字建议正文16–18屏幕像素、辅助信息不小于14；主按钮触区至少40像素高。固定像素尺寸只作首轮校准，实际中文溢出、缩放和键盘焦点都要测。
- 使用一致的状态色：中性信息、友方选择、可行动、危险、禁用。颜色之外同时给形状或文字。HUD不模拟不存在的“可捕获”“可施法”状态。
- 移动/攻击预览必须能取消，取消后返回原选择且不消耗资源；执行前后数值清楚。结束回合与普通待机不能共享容易误按的位置。

## 战斗可用性验收

视觉验收与规则验收分开记录：导入成功不等于画质通过，点选地面不等于能移动，自动回放不等于真人通关。

1. 从真实新战役进入C01，验证开局选择、角色、目标与资源，不用旧场景存档证明新场景。
2. 同一真实角色、同一回合，对比邻接墙拒绝与邻接合法地实际移动；保存执行前后状态、事件及RNG差异。镜头内目标、邻兵与建筑分别点选，预测/取消/确认都实跑。
3. 验证每个真实坡口双向通过、撤退与再推进；验证建筑遮挡的LOS，不把美术影子当视线规则。重要单位站在屋檐前后都能辨认脚点。
4. 两个开局策略各有合法完整胜利与战役后续进入证据；记录伤亡与首接敌，不用调低敌HP、改随机数或跳过目标获得结果。
5. 在实际960窗口连续平移镜头至少5秒，经过屋顶、台阶边、远近人物与植被，再反向返回。看录像/连续帧而非只看静帧：不得出现闪烁白点、细线爬动、透明边彩点、接缝漏光、排序跳跃或单位忽隐忽现。失败就定位采样、透明边、深度或材料频率原因，不以静态锐化掩盖。
6. 固定同一设备与渲染后端记录帧时/峰值和旧基线；不从截图工具读回帧率声称游戏性能。包装后的实际程序复核纹理、字体、输入和首场加载。
