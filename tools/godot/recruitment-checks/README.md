# Recruitment action parity

Run `bash tools/godot/recruitment-checks/run.sh` from the repository root.
Checks all nine original recruitable types with immediate/delayed action rights, resource costs, next-unit IDs, ordered events, and full resulting states. Covers off-board, incompatible terrain, enemy/unowned building, insufficient funds, unit cap and occupied-site refusals through the real transactional engine.
