# Persistence checks

From the repository root:

```sh
source tools/godot/env.sh
dotnet run --project tools/godot/persistence-checks/Empire.Persistence.Checks.csproj -- .
```

Checks source save/replay documents for all three GrayFlag aggression fixtures, midbattle save/load/resume through every remaining action, detached save/header/recorder ownership, exact manifest identity, named shape failures, content and capability refusals, malformed coordinates/counters, and replay divergence boundaries. Unexpected domain defects must propagate instead of being reported as ordinary illegal actions.

The harness uses the production engine's manifest, live reference-check owners, replaceable save reader, and replay façade. Three former native-only refusals now assert detached roundtrips instead: an unknown resource account, an unused upkeep resource, and a condition nested within an objective. Their source load and later-use boundaries are differential-tested in `../persistence-reference-checks`. Structural, coordinate, counter, identity, version, schema, and aggregate safety negatives remain unchanged.
